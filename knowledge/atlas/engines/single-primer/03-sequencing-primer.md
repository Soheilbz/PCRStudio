## Scope

This module designs a single sequencing primer from a known template region and reports its orientation, expected read direction and distance from the region of interest. The primer is not a PCR pair, and the result must include the sequencing chemistry/platform and template preparation assumptions because read quality is not determined by oligo sequence alone ([Specific-primer-directed DNA sequencing](https://pubmed.ncbi.nlm.nih.gov/3010776/), [Design strategies for sequencing primers](https://pubmed.ncbi.nlm.nih.gov/10489613/)).

The module owns read direction, target offset, primer uniqueness and sequencing handoff metadata. It must not promise a fixed read length or base-level accuracy across instruments and reagent generations ([Design strategies for sequencing primers](https://pubmed.ncbi.nlm.nih.gov/10489613/)).

## Vendor protocol overlay: Applied Biosystems BigDye Terminator v3.1

The BigDye v3.1 user guide recommends sequencing primers of at least `18 bases`, HPLC purification, avoidance of secondary structure/dimers, and a GC-content range of `30–80%`; it also states that primers with Tm above `45 °C` generally perform better for this cycle-sequencing chemistry. These are named-kit recommendations and are not candidate defaults for every sequencing chemistry ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

When `sequencing_protocol=bigdye-v3-1` is selected, the runtime emits one versioned protocol object containing the kit family, `10/20 µL` reaction options, `3.2 pmol` primer input, `96 °C` initial denaturation for `60 s`, `25` cycles of `96 °C / 10 s`, `50 °C / 5 s`, `60 °C / 240 s`, a `1 °C/s` ramp-rate note and a `4 °C` hold. Those values are taken from the current Thermo Fisher guide; they are not inferred when the selector is absent ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

The same object records the guide's template-input ranges for PCR products and double- or single-stranded DNA, plus the supported cleanup families: BigDye XTerminator, ethanol/EDTA precipitation, or spin-column/plate purification. Cleanup is a required downstream decision because residual dye terminators, salts and dNTPs can interfere with injection, peak intensity and early basecalling ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf), [BigDye Terminator v3.1 FAQ](https://www.thermofisher.com/order/catalog/product/4337454/faqs)).

The BigDye guide's template table is retained verbatim as a mass-by-length record: PCR products of `100–200 bp` use `1–3 ng`, `200–500 bp` use `3–10 ng`, `500–1000 bp` use `5–20 ng`, `1000–2000 bp` use `10–40 ng`, and products `>2000 bp` use `20–50 ng`. The guide lists `25–50 ng` for single-stranded DNA, `150–300 ng` for double-stranded DNA, `0.5–1.0 µg` for cosmid/BAC templates and `2–3 µg` for bacterial genomic DNA. These are template inputs for the named BigDye v3.1 cycle-sequencing chemistry, not universal Sanger limits ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

For the standard reaction the same guide specifies `20 µL` total volume, `8 µL` BigDye Ready Reaction Mix and `3.2 pmol` primer. Revision B also labels the primer stock as `3.2 µM` while showing a `2 µL` primer example for the 20-µL reaction and `1 µL` for the 10-µL reaction; those columns are not arithmetically self-consistent with the stated `3.2 pmol` quantity. PCRStudio therefore preserves `3.2 pmol` as the supplier-stated reaction quantity and records the document ambiguity rather than calculating or emitting a stock-volume recipe from the conflicting columns. The reaction can be scaled to `10 µL` for 384-well plates; bench setup must follow the current supplier guide/SOP rather than a software-reconciled volume. Template quality is also quantified: the guide gives an A260/280 target of `1.8–2.0` and recommends an optical-density window of `0.05–1.0` when OD-based concentration is used. A high OD (`>1.0`) or very low OD (`<0.05`) is flagged as an inaccurate quantification region, and PCR products are directed to gel or fluorescence quantification instead of blindly applying the OD rule ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

The module therefore keeps `template_class`, `template_length`, `template_mass`, `reaction_volume`, `ready_reaction_mix_volume`, `primer_pmol`, `template_volume`, `A260_280`, `OD260`, `cleanup_method`, `cycle_program` and `instrument/dye-set` as separate fields. A primer that satisfies the sequence baseline must not be reported as a sequencing-ready submission until the template and cleanup record is complete ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

The module preserves the selected object in the result and portable report, but it still does not infer read quality, usable read length, base confidence, instrument compatibility or a successful cleanup. The vendor guide distinguishes BDX from non-BDX instrument run modules and documents platform-specific dye-set/mobility settings, so the instrument and current facility SOP remain explicit handoff responsibilities ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

Sequencing-facility guidance gives a useful independent operational cross-check: Cornell recommends `17–25 nt` primers, approximately `55–65 °C` Tm, an exact match across the last eight bases and caution that the first `50–500` read bases are the more reliable region. These are facility-specific starting recommendations, not universal Sanger laws; the module therefore records them as an external comparison and does not overwrite the selected chemistry profile ([Cornell Sanger primer-design guidance](https://www.biotech.cornell.edu/core-facilities-brc/facilities/genomics-facility/qc-troubleshooting/sanger-sequencing-primer-design)).

The BigDye guide also recommends HPLC purification and warns against runs of four or more identical bases, particularly G. It documents an M13 workflow in which the M13 sequence is placed at the 5′ end of the PCR primer before amplification; the kit guide lists the forward sequence as `TGTAAAACGACGGCCAGT` and the reverse sequence as `CAGGAAACAGCTATGACC`. The runtime must therefore distinguish a gene-specific sequencing primer from an M13 universal primer and must reject an M13 protocol selection when the submitted amplicon does not contain the selected tail ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf), [BigDye Terminator v3.1 FAQ](https://www.thermofisher.com/order/catalog/product/4337454/faqs)).

The vendor's control and failure guidance adds two operational boundaries that belong in the handoff record. A BigDye v3.1 control reaction uses `8 µL` Ready Reaction Mix, `4 µL` `0.8 pmol/µL` −21 M13 control primer, `1–2 µL` pGEM at `200 ng/µL`, and water to `20 µL`; this is a reagent/system control, not a template-mass default. The vendor also reports that BigDye v3.1 with POP-7 typically has optimized data quality after the first `35–40` bases, while other kit/polymer combinations can behave differently. Hairpins and other template secondary structures can cause an abrupt read stop; vendor troubleshooting mentions reported but unvalidated `5–10%` DMSO/betaine/glycerol additives, which must remain an optional laboratory troubleshooting note rather than an automatic recommendation ([Thermo Fisher Sanger sequencing troubleshooting](https://www.thermofisher.com/us/en/home/technical-resources/technical-reference-library/capillary-electrophoresis-applications-support-center/sanger-sequencing-support/sanger-sequencing-support-troubleshooting.html), [Thermo Fisher Sanger primer guidance](https://www.thermofisher.com/order/catalog/product/A15630/faqs)).

Sequencing-reaction cleanup is not interchangeable with PCR-product cleanup. Thermo Fisher's guidance notes that dye-terminator extension products are single stranded and begin at primer `+1`, so a cleanup intended to remove short PCR primers/products can also remove useful sequencing extensions. The workflow must record the selected cleanup family—BigDye XTerminator, ethanol/EDTA precipitation or a spin column/plate method—and leave method-specific bead, salt and centrifugation settings to the selected cleanup protocol rather than inventing a universal value ([BigDye XTerminator FAQ](https://www.thermofisher.com/order/catalog/product/4376484/faqs), [BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

## Current BigDye v3.1 document revision and instrument-state overlay

The current Thermo Fisher BigDye Terminator v3.1 Cycle Sequencing Kit guide is publication `MAN1000355`, **Revision B**, dated `17 July 2026`. Revision B updates spectral-calibration sequencing standards and expands BigDye XTerminator instructions; it supersedes Revision A (`28 June 2024`) for current document provenance. The guide also states that the kit reagents should undergo no more than `10` freeze–thaw cycles, are compatible with SeqStudio, SeqStudio Flex, 3500/3500xL and 3730/3730xl DNA analyzers, and warns that thermal ramping faster than `>1 °C/s` may produce poor/noisy data. These are current kit/document and instrument-handling facts; they do not alter the sequence-only primer candidate contract or guarantee read quality ([BigDye Terminator v3.1 User Guide, MAN1000355 Rev. B](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

## Evidence

The cited sequencing studies support specific-primer Sanger initiation and the need to account for template/chemistry context, but they do not support one universal read-length guarantee or one mandatory primer composition for all platforms ([Specific-primer-directed DNA sequencing](https://pubmed.ncbi.nlm.nih.gov/3010776/), [Design strategies for sequencing primers](https://pubmed.ncbi.nlm.nih.gov/10489613/)).

## Verification record

**Implementation:** validate strand, target offset and uniqueness against the declared template/background; accept the BigDye overlay only for the sequencing-primer assay; preserve instrument family (including an explicit `unresolved` state), optional facility/SOP and protocol object in the result; keep trace/basecalling/quality claims unresolved until handoff; when a bounded ABIF/AB1 file is imported, report basecalls, quality, longest contiguous Q20 interval, mixed-peak evidence and channel traces as post-run evidence without changing the saved primer ranking ([Specific-primer-directed DNA sequencing](https://pubmed.ncbi.nlm.nih.gov/3010776/), [BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

**Test:** cover reverse-strand input, target near the read start, repeated template matches, missing platform and unresolved quality state; additionally verify that an unknown protocol is refused, a selected BigDye overlay reaches the worker and result schema, it cannot leak into RACE, and the report retains the cycling/cleanup handoff ([Design strategies for sequencing primers](https://pubmed.ncbi.nlm.nih.gov/10489613/), [BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).

**Limitation:** this profile is `limited`; electropherogram quality and base-level confidence require the actual sequencing run ([Design strategies for sequencing primers](https://pubmed.ncbi.nlm.nih.gov/10489613/)).


### Current closure additions

**Primer walking and universal-primer reuse:** long targets can be partitioned into deterministic overlapping read windows only when the requested overlap is shorter than the declared usable read length. Curated universal primers are reusable only after exact, orientation-correct, unique binding on the submitted template; multiple binding sites remain non-orderable. Imported AB1 evidence is bounded and post-run only ([BigDye Terminator v3.1 User Guide](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN1000355-BDTv3-1CycleSeqKit-UG.pdf)).
