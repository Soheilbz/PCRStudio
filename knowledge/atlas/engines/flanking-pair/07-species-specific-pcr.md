This record will audit inclusivity and exclusivity design, mismatch position and tolerance, background composition, off-target search completeness, hard-fail versus ranking policy, and the evidence required before calling a pair diagnostic ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/), [Appendix Q](https://pmc.ncbi.nlm.nih.gov/articles/PMC8370429/)).

**Internal software contract.** The executable `species-specific-pcr` path now fails closed in every policy mode unless it receives both a non-empty exclusion background and a separate, non-empty inclusivity panel: FASTA records for intended strains or variants that every returned pair must amplify in silico. There is no development-mode escape hatch that turns one representative target sequence into a species-wide result. Each panel must also carry separate source/version provenance and a selection rationale; PCRStudio records those declarations but does not independently certify their taxonomic completeness. The scientific rationale for this finite-panel boundary is described by the [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/); the fail-closed binding itself is an application behavior, not external scientific evidence.

**Internal software contract.** The inclusivity/exclusivity gate now follows a **pinned per-record metadata manifest**. Every FASTA record is mapped to one exact `accession.version`, a role (`inclusivity` or `exclusivity`) and a topology (`linear`, `circular` or `fragment`), with optional user-declared relative population weight and group label. Circular records are scanned across their own FASTA origin; linear and fragment records are not wrapped. Fragment status is evidence-limited and does not imply that unsubmitted sequence is absent. Optional weights/groups are summarized for population-evidence bookkeeping only: every returned pair must still satisfy the strict all-inclusivity-record sequence gate, and weights never relax that gate or alter sequence ranking.

**Internal software contract.** The exclusion/background side uses the same per-record topology contract instead of inheriting a target-wide flag. This removes the former mixed-topology ambiguity and makes circular plasmids/chromosomes, linear complete records and fragments coexist reproducibly in one pinned panel. The record-metadata manifest and accession manifest are canonicalized before hashing, so comments, whitespace and row ordering do not create a new scientific snapshot. A changed accession version, added/removed accession or changed metadata record remains detectable by the surveillance/diff utility.

This remains an in-silico inclusivity/exclusivity check: circular topology repairs a coordinate-boundary artifact, but it does not establish that every biological isolate carries the submitted sequence or that the reaction amplifies it in the laboratory ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).

**Panel-identity boundary.** PCRStudio fingerprints the ordered normalized FASTA record names and sequences for both inclusivity and exclusivity panels. That hash is a reproducibility identifier for the exact submitted content, not a taxonomic certificate. The runtime also refuses exact sequence content that appears in both panels: one identical sequence cannot coherently be classified as both must-amplify and must-exclude under a sequence-discrimination claim. This is a logical content-overlap guard only; it does not infer taxonomy or claim that non-identical records are biologically distinct. Users should preserve accession/version, isolate/strain and taxonomy context in FASTA headers where available, and separately document the rationale used to choose representative target diversity and near-neighbour/matrix backgrounds. This distinction is consistent with ISO 22174:2024's emphasis on comparable/reproducible PCR results and with NCBI Primer-BLAST guidance to choose the organism/database scope deliberately; neither source permits a finite sequence file to be treated as proof that all biological diversity has been represented ([ISO 22174:2024](https://www.iso.org/standard/81777.html), [NCBI Primer-BLAST guide](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/)).

### R12 population-evidence and surveillance boundary

The exact record manifest can now carry optional relative weights and group labels (for example lineage, strain group, geography or collection stratum). PCRStudio reports these as **user-declared evidence only** and continues to require every inclusivity record to pass; it does not turn weights into a permissive prevalence threshold or infer a pangenome from a finite panel. The snapshot utility also compares pinned `accession.version` manifests and reports additions, removals and version replacements so a later database review can identify exactly what changed. Whole-database BLAST+/MFEprimer evidence remains an independent, database-fingerprinted validator; neither the local finite-panel scanner nor the manifest diff is relabeled as organism-wide specificity ([NCBI Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/), [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).

### Runtime panel-identity boundary (2026-09-04)

The runtime now records a positive declared `speciesTargetTaxid`, a named taxonomy snapshot, a named sequence-database snapshot, an `accession.version` manifest and an ISO retrieval date in addition to hashing the submitted inclusivity/exclusivity FASTA. The accession manifest itself is hashed in the result. These fields make the reviewed panel and database context reproducible, but PCRStudio deliberately reports `user-declared-taxid-and-snapshot-recorded-not-independently-resolved` and `panel_completeness_status=not-inferred-or-claimed`: it does not resolve taxonomy from FASTA labels, infer population representativeness or claim that a finite panel is still complete after future database releases. NCBI Primer-BLAST likewise makes specificity dependent on the database and organism/taxonomic scope selected for the search, so those authorities must remain part of the reproducibility record rather than being hidden behind a generic “specific” label ([NCBI Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/), [NCBI primer-design guidance](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/), [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
## Evidence collected

Species-specificity is a comparative claim, not a property inferred from primer GC, Tm, or one target sequence. A defensible workflow needs an inclusivity set (target diversity that must amplify), an exclusivity set (near neighbours and likely matrix organisms that must not amplify), and in-silico checks against both, followed by representative wet-lab testing ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/), [Appendix Q](https://pmc.ncbi.nlm.nih.gov/articles/PMC8370429/)).

The development stages must remain distinguishable: construct and curate the reference database, evaluate the target locus phylogenetically, design the primers, screen them in silico, then test specificity, sensitivity and utility in the laboratory. This nine-step separation is explicitly proposed for taxon-specific assays and is important because early computational suitability cannot close the later false-positive/false-negative or field-utility questions ([MacDonald & Sarre](https://pubmed.ncbi.nlm.nih.gov/27768246/)).

Terminal mismatches can reduce extension, especially near the 3-prime end, but their effect depends on mismatch identity, neighbouring bases, polymerase and conditions. A 3-prime mismatch is evidence for ranking and review, not a universal hard guarantee ([Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/)).

**Internal screening-method boundary.** The direct supplied-panel scanner uses a versioned, finite **ungapped whole-primer mismatch discovery envelope**. PCRStudio Gen-1 currently fixes that internal discovery budget at `3` mismatches for this module as a reproducibility/search-cost decision of specificity-v5; `3` is not attributed to SpeciesPrimer and is not a biological threshold for amplification or non-amplification. Its mismatch budget is an implementation/search-method boundary, not a biological statement that sites beyond that number cannot amplify. NCBI Primer-BLAST exposes mismatch stringency as a configurable search parameter and its high-sensitivity workflow can recover substantially more mismatched targets before applying pair-level interpretation. Accordingly, absence of a product in the direct supplied-panel scan is reported only within that declared envelope; broader database evidence remains separate and is not silently upgraded to an organism-wide specificity verdict ([Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/index.cgi?GROUP_TARGET=on), [Ye et al. 2012](https://pmc.ncbi.nlm.nih.gov/articles/PMC3412702/)).

## Marker and locus selection rules

The first design decision is the claim, not the primer. Define the target taxon, the intended sample/matrix, the intended use (screening, detection, confirmation or typing), and the non-target universe before choosing a locus. The reference sequence set must be curated with accession/version, assembly or record provenance and taxonomic rationale; NCBI RefSeq is a curated, non-redundant reference resource, but its existence does not make any taxon or locus complete. A species-level claim is therefore bounded by the database, sampling frame and use case that were actually evaluated ([MacDonald & Sarre](https://pubmed.ncbi.nlm.nih.gov/27768246/), [NCBI RefSeq](https://www.ncbi.nlm.nih.gov/refseq/), [FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=)).

Use GenBank/INSDC records for archival sequence breadth and RefSeq for curated reference anchors, but preserve both the accession.version and the database/release date. NCBI Taxonomy maps sequence records to taxonomic nodes and supplies current names and synonyms, yet NCBI explicitly cautions that the Taxonomy Browser is not the authoritative source for nomenclature or classification; final taxon assignment must be checked against the relevant primary taxonomic literature or other authoritative authority. This prevents stale names or ambiguous labels from silently contaminating an inclusivity/exclusivity panel ([NCBI GenBank](https://www.ncbi.nlm.nih.gov/genbank/), [NCBI Taxonomy](https://www.ncbi.nlm.nih.gov/taxonomy), [NCBI Taxonomy disclaimer](https://www.ncbi.nlm.nih.gov/Taxonomy/Browser/wwwtax.cgi?id=0), [NCBI sequence identifiers](https://ncbi.nlm.nih.gov/genbank/sequenceids/)).

Select a region that is conserved across the intended target diversity and discriminatory against the closest relatives and relevant co-occurring background. The conserved-within-target/divergent-between-taxa rule is an assay-development objective, not a universal gene recommendation: a bacterial workflow used single-copy core genes, consensus sequences and a non-target list as one worked example, while a fish study showed that local intraspecific polymorphism and unresolved taxonomy can make a generally applicable marker impossible. When the taxon is polyphyletic, poorly sampled or not separable at the requested rank, the correct outcome is a lower-confidence or narrower claim, not an over-specific primer label ([SpeciesPrimer](https://pmc.ncbi.nlm.nih.gov/articles/PMC7034379/), [Wilcox et al.](https://pubmed.ncbi.nlm.nih.gov/26536367/)).

Variant masking or degeneracy must be explicit. A consensus primer can improve target inclusivity, but every degenerate position expands the oligonucleotide pool and may create new non-target matches; therefore retain the unmasked alignment, the exact degeneracy, the affected target records and the resulting exclusivity search. In one bacterial pipeline, continuous consensus segments used for primer design were required to contain fewer than `2` ambiguous bases in any `20`-base region, and the product manual separately recommends at least `3` conserved nucleotides at the 3′ end of degenerate primers. These are workflow/vendor conditions, not universal limits; masking a known target polymorphism without rechecking non-targets is not acceptable ([SpeciesPrimer](https://pmc.ncbi.nlm.nih.gov/articles/PMC7034379/), [DreamTaq Green manual](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0012704_DreamTaq_Green_PCR_MasterMix_K1081_UG.pdf)).

The in-silico locus gate should search both primer oligonucleotides and the complete predicted amplicon against a declared database. Primer-BLAST evaluates forward–reverse, forward–forward and reverse–reverse orientations and allows the user to choose an organism/taxonomic scope; the smallest suitable database gives more precise results, while broad searches use `nr` without an organism restriction. A candidate that has a clean primer-only search but a homologous full amplicon, an alternative orientation, or a second genomic binding site is not a clean species-specific candidate ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [NCBI Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/primertool.cgi/primerinfo.html), [Primer-BLAST guide](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/)).

In-silico specificity is a triage step, not a wet-lab substitute. In one study of 38 primer pairs across 13 fish/turtle taxa and five mitochondrial loci, `679` conventional PCR reactions included `93` target and `586` non-target reactions; `182` non-target reactions produced nonspecific bands. Specificity was validated for only `11/38` pairs by cPCR and `4/12` pairs by qPCR, with only `3` pairs specific in both, while Primer-BLAST prediction accuracy was about `67%` and sensitivity for nonspecific amplification was only `29–57%`. This study-specific result supports reporting prediction-versus-experiment separately and testing the actual chemistry and non-target panel ([So et al.](https://esajournals.onlinelibrary.wiley.com/doi/10.1002/ecs2.3193)).

Mixed-template competition is an additional endpoint failure mode. In a rare-species detection study, a dominant non-target could make the amplified product and subsequent sequencing uninformative; the authors therefore emphasize testing pure target, pure non-target and mixed target/non-target templates and maximizing discriminatory primer differences in the primer-binding regions. A target-sized band in a mixed sample must therefore be interpreted with the competition design, template proportions and orthogonal identity method recorded, rather than treated as equivalent to a pure-target result ([rare-species detection study](https://pmc.ncbi.nlm.nih.gov/articles/PMC3608683/)).

Do not use a finite panel, a percent identity, a GC/Tm score or a single reference genome as a substitute for target-population coverage. Samples for inclusivity should reflect genetic diversity and should include close variants and cases near the sensitivity limit; exclusivity should include close relatives and likely co-occurring non-targets. The number of organisms is use- and taxon-dependent in FDA nucleic-acid guidance, and the FDA food-method appendix explicitly says its suggested panels are a starting point rather than exhaustive ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [FDA Foods Program Guidelines, Appendix 6](https://www.fda.gov/media/83812/download)).

## Inclusivity/exclusivity panel construction

Panel roles are mutually informative but must remain separate. Inclusivity records are intended target strains, isolates, variants or lineages that the pair must amplify; exclusivity records are close relatives, non-target species, matrix organisms or other organisms that the claim says must not generate a reportable product. Every record should retain accession or strain identifier, taxon, source/origin, sequence version, panel role and reason for inclusion. FDA guidance requires strains to be fully characterized and traceable to their original source; it also recommends choosing inclusivity for genetic/serological/biochemical diversity and exclusivity for potentially cross-reactive organisms ([FDA Foods Program Guidelines](https://www.fda.gov/media/83812/download)).

The following numeric designs are conditional published validation patterns, not module defaults. FDA’s general qualitative food-pathogen guidance gives a single-laboratory example of `50` target organisms unless fewer are available and `30` non-target strains; target material is tested at `10–100×` the candidate method’s LOD50, while non-targets are grown in non-selective rich medium at the growth limit (the table notes `10^9 CFU/ml` for target organisms). The qualitative matrix study uses `3` levels, including a fractional-positive level and a level `1 log` higher, with `20` replicates at the fractional level and `5` each at uninoculated and high levels. Its multi-laboratory column uses `8` replicates per level, `10` collaborating laboratories, and a competitor at `+1 log` over analyte at the fractional-positive level. These values apply to the cited FDA food-method validation design, not to all species, matrices, platforms or endpoint assays ([FDA Foods Program Guidelines, Table 1](https://www.fda.gov/media/83812/download)).

The FDA’s current Cronobacter BAM method illustrates why panel counts must travel with the assay: its qPCR inclusivity study used `52` strains representing `7` Cronobacter species, tested at approximately `10×` the LOD, and its exclusivity study used `51` non-Cronobacter strains selected on taxonomic grounds. The method states that qPCR positives are screening results and should be confirmed by culture; this is a method-specific confirmation rule, but it is a useful warning against treating an endpoint band or an in-silico hit as an organism identity by itself ([FDA BAM Chapter 29 — Cronobacter](https://www.fda.gov/media/173834/download)).

Panel completeness remains an external biological claim rather than a status inferred from FASTA count. The executable path refuses an empty exclusivity or inclusivity panel, retains the supplied record counts and panel provenance, and reports `diversity_coverage_status=not-computed-from-panel-hash`, `biological_traceability_status=user-declared-provenance-recorded-not-independently-validated`, `population_frequency_status=not-computed`, and `surveillance_status=external-versioned-review-required`. The user/validation record must separately state which target lineages, close relatives, matrix organisms, database releases or sensitivity levels were not evaluated; a non-empty finite panel is reproducible screening evidence, not proof of population completeness or laboratory specificity ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [MacDonald & Sarre](https://pubmed.ncbi.nlm.nih.gov/27768246/)).

## Discriminatory sequence rules

Mismatch evidence must retain exact mismatch identity, position measured from the primer 3′ end, primer orientation, local sequence context and chemistry. In a conventional HIV-1 PCR model, internal single mismatches had little effect, while 3′-terminal `A:G`, `G:A` and `C:C` mismatches reduced product yield by about `100-fold`, `A:A` by about `20-fold`, and several other terminal mismatches were efficiently amplified; a terminal `T` could remain permissive even with an adjacent mismatch. These are measured conditions in one assay system, not a universal hard-fail table ([Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/)).

The direction of the evidence is consistent but not interchangeable across chemistries. In a 5′-nuclease/qPCR study, single 3′-region mismatches ranged from less than `1.5` cycle threshold to more than `7.0` cycle threshold depending on mismatch type, position and master mix; the overall effect differed by as much as `7-fold`, and forward-versus-reverse primer effects were observed. Those values support chemistry-specific review and wet-lab testing, not an endpoint-PCR universal threshold ([Stadhouders et al.](https://pubmed.ncbi.nlm.nih.gov/19948821/)).

Intentional discrimination should be designed around the target/non-target alignment and then experimentally challenged. A published SpeciesPrimer workflow discarded candidate conserved regions when a non-target matched the primer-binding region unless there were more than `3` mismatches in each primer-binding region, required no 3′-end mismatch in target binding sites, and separately screened predicted amplicons; those are that pipeline’s criteria, not a generally validated species-specific rule ([SpeciesPrimer](https://pmc.ncbi.nlm.nih.gov/articles/PMC7034379/)). The current module therefore exposes its mismatch ceiling and search model but does not translate a “weaker” duplex into species-specific safety: any complete product inside the declared finite-panel sequence envelope is a conservative contradiction, while mismatch position/thermodynamics remain descriptive evidence for laboratory review.

Primer-BLAST’s current user guidance also demonstrates why the search envelope must be recorded: its specificity checker describes detection of targets up to `35%` mismatches, equivalent to `7` mismatches for a `20`-mer, and warns that more divergent targets may require more sensitive BLAST settings. The value is a search-behaviour limit of that tool/configuration, not a biological cutoff for amplification or exclusivity ([NCBI Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/index.cgi?GROUP_TARGET=on)).

## Endpoint chemistry and platform branches

The endpoint result is chemistry- and platform-bound. Store polymerase or master-mix product, catalog/format, revision, template type and amount, primer concentrations, dNTP/Mg²⁺ conditions, cycling program, product-size window, gel/readout method and any downstream sequencing or orthogonal confirmation. A vendor starting recipe is a starting condition, not evidence of species specificity; changing polymerase, buffer, dNTP composition, annealing rule, cycle count or readout requires a verification decision ([ISO 22174:2024](https://www.iso.org/standard/81777.html), [FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=)).

Its optimized program was `15 min at 95 °C`, `35` cycles of `94 °C/30 s`, `65 °C/3 min`, `72 °C/60 s`, then `72 °C/10 min` ([celPCR study](https://pmc.ncbi.nlm.nih.gov/articles/PMC8301609/)). The `10 µL` reaction used Qiagen Multiplex PCR Kit, `5 µg` BSA, `30 mM` TMAC and `3.2 µL` extract; the study observed species- and multiplex-dependent RFU differences, so singleplex and multiplex performance were not assumed equivalent ([celPCR study](https://pmc.ncbi.nlm.nih.gov/articles/PMC8301609/)). | Treat capillary RFU, amplicon-length separation, inhibitor additives and multiplex competition as platform-specific claims; do not substitute a capillary threshold for agarose-band interpretation or transfer its multiplex conditions to another kit. |
| GeneOn Maximo Taq 2X-preMix | In a recent endpoint species-authentication study, the named 2X mix included ammonium sulfate; the authors describe ammonium ions as destabilizing weak hydrogen bonds and mismatched bases in non-target loci and primer dimers, thereby favoring specific product yield. ## Controls, failure modes and validation gates

The minimum endpoint control set should distinguish reagent contamination, extraction contamination, inhibition/reaction failure, target presence and non-target cross-reactivity. A no-template control contains reaction components without sample nucleic acid and is intended to reveal reagent contamination or background signal; CDC guidance also recommends unidirectional clean-to-dirty workflow, dedicated equipment/PPE and filtered tips. If an NTC produces the reportable target band, the run is contaminated/invalid until investigated and repeated; the presence of a target-sized band in a sample does not repair a failed control ([DreamTaq Green manual](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0012704_DreamTaq_Green_PCR_MasterMix_K1081_UG.pdf), [CDC False-Positive Investigation Toolkit](https://cdc.gov/tb/php/false-positive-investigation-toolkit/prevention-practices.html)).

An extraction blank is required when extraction is part of the claim because it detects contamination introduced during extraction; FDA sequence-based guidance requires extraction blanks and empirical extraction-efficiency data for each matrix. A positive extraction/amplification control should demonstrate recoverable target through the intended process, while an internal amplification or endogenous/group control is needed when a negative sample could also be an inhibited or failed reaction. The exact control sequence, amount, matrix and acceptance rule must be recorded; an IAC copy number from another assay is not portable ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [Malorny et al.](https://pmc.ncbi.nlm.nih.gov/articles/PMC152403/), [eDNA control study](https://pubmed.ncbi.nlm.nih.gov/27802293/)).

For endpoint gel interpretation, the following failure modes are separate: no product in a positive control (reaction, template, cycling or chemistry failure); product in an NTC/extraction blank (contamination); a wrong-size, multiple or smeared band (non-specific amplification, primer-dimer, template overload, inhibition or gel/readout issue); target-sized product in a non-target (cross-reactivity); and target-sized product in a target without orthogonal identity confirmation (identity unresolved). Thermo’s manual specifically links excess template to non-specific products and primer concentration/cycling to non-specific bands, while FDA guidance requires theoretical and experimental specificity testing of primers, probes and amplicons ([DreamTaq Green manual](https://documents.thermofisher.com/TFS-Assets/LSG/manuals/MAN0012704_DreamTaq_Green_PCR_MasterMix_K1081_UG.pdf), [FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=)).

An endogenous/group control can make a negative species-specific lane interpretable, but a duplex control can also introduce primer interaction artifacts. In a recent endpoint species-authentication study, non-targets were expected to show only an approximately `220 bp` universal-control band while targets showed the control plus the species-specific band; however, interaction artifacts prevented use of the internal control for two assays, so the authors interpreted those non-target tests by total absence of product after independently checking DNA quality. The module should therefore report `control_present`, `control_failed`, and `control_not_run` separately rather than treating “no species band” as a standalone negative ([Peruvian marine species study](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0313181)).

Validation must be staged: sequence/database and in-silico specificity; analytical inclusivity/exclusivity; extraction and matrix inhibition; sensitivity/LOD; repeatability and robustness; then inter-laboratory or intended-use verification and orthogonal confirmation where the claim requires identity. ISO 22174:2024 sets general requirements for in-vitro amplification of DNA/RNA and is explicitly applicable to food-chain PCR. ISO 16140-3:2021 is the current confirmed single-laboratory verification standard for validated reference/alternative methods in the food chain, while ISO 16140-4:2020 covers single-laboratory validation of in-house methods and has current 2024 and 2025 amendments for larger test portions and identification methods. These standards define scope and validation/verification frameworks, not a universal primer mismatch or species-specificity cutoff ([ISO 22174:2024](https://www.iso.org/standard/81777.html), [ISO 16140-3:2021](https://www.iso.org/standard/66324.html?browse=tc), [ISO 16140-4:2020](https://www.iso.org/standard/66325.html), [ISO 16140-4:2020/Amd 1:2024](https://www.iso.org/standard/83201.html), [ISO 16140-4:2020/Amd 2:2025](https://www.iso.org/standard/88179.html), [MacDonald & Sarre](https://pubmed.ncbi.nlm.nih.gov/27768246/)).

For nucleic-acid sequence-based methods, FDA guidance defines an approximate LOD95% as the concentration at which amplification is detected with probability at least `0.95`; it describes a dilution series with `12` PCR replicates per dilution and calls the lowest-copy level with all `12` positive an approximate LOD95%, expressed as target mass or copy number per reaction, followed by matrix-specific estimation. For qualitative food-method verification, FDA separately gives a `50% ± 25%` fractional-positive target for inoculated samples, and for first-use verification gives `6` inoculated plus `6` uninoculated matrix replicates; a commodity should be spiked near LOD, usually `<30 CFU` per `25 g` food sample, to test matrix interference. These are scope-specific guidance values, not universal acceptance criteria for this engine ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [FDA Foods Program Guidelines](https://www.fda.gov/media/83812/download)).

If the selected purpose is identification/confirmation rather than detection, FDA’s separate identification-method table uses a different design: for a non-Salmonella species-level claim it lists `100` target strains and at least `100` non-target strains in the single-laboratory criterion, with material at `10^3 CFU/ml` or `10^3 CFU/reaction` for molecular methods; inclusive and exclusive samples should be intermingled and blinded and the strains fully characterized before use. These values belong to an identification-method study and must not be silently applied to a screening/detection claim ([FDA Foods Program Guidelines](https://www.fda.gov/media/83812/download)).

Acceptable false-positive and false-negative rates must be pre-specified for the intended use; FDA states that replicate number and whether the method is for emergency, screening or confirmatory use influence the decision. A positive uninoculated control can invalidate a data set, and a platform, matrix, extraction method, primer concentration or polymerase change requires a documented verification decision rather than silent reuse of an earlier validation ([FDA Foods Program Guidelines](https://www.fda.gov/media/83812/download), [FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=)).

A finite sequence background can never prove absence of cross-amplification against taxa that were not sampled or lack sequence data. Wilcox et al. (2024) formalized this “unknown unknown” problem for taxon-specific qPCR and showed how cross-amplification risk can be modeled from available confamilial data when some non-target taxa are unsampled. PCRStudio should therefore preserve taxonomic/database coverage and missingness as part of the specificity claim instead of promoting a clean finite-panel screen to universal species exclusivity ([Wilcox et al. 2024](https://pubmed.ncbi.nlm.nih.gov/38263813/)).

The current FDA nucleic-acid validation guidance also gives an explicit false-result criterion that should not be lost in a generic “pre-specify acceptance criteria” statement: false-negative and false-positive rates should **each be `<5%`** using a valid statistical approach. FDA defines the false-negative condition relative to a truly positive sample present at a concentration at or above the method LOD, so this requirement belongs to empirical method validation with traceable truth status and a defined LOD; it is not computable from Primer3/BLAST output and must not become an in-silico specificity score ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=)).

## Current implementation assessment

**Internal software-contract observations:** The statements in this section are retained for the module audit. Citations attached to a row support the scientific rationale or limitation; they do not independently verify repository implementation.

- Requiring a background is correct and safer than reporting a pair as species-specific from the target alone ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
- Inclusivity and exclusivity are separate **required** data paths. The executable species-specific branch refuses the request unless both panels are supplied, every panel carries separate source/version provenance plus a selection rationale, and every retained pair forms a left/right product on every inclusivity record before it can reach the exclusion gate. A pair that rejects all supplied relatives but misses one intended strain is therefore not returned under a species-specific label ([Appendix Q](https://pmc.ncbi.nlm.nih.gov/articles/PMC8370429/)).
- There is no target-only fallback in the executable species-specific path. One representative pasted template can seed primer discovery, but it does not substitute for the separately supplied intended-target panel. This fail-closed rule is an application contract chosen to prevent a one-sequence design from being presented as a species-wide result ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
- The worker rejects an empty/malformed FASTA instead of silently weakening the claim. Background and inclusivity records are checked for DNA/IUPAC characters (with RNA `U` normalised to `T`) and unique record identifiers, so arbitrary text, empty records or silently merged panel members cannot be reported as a clean finite comparison. This is an application safety rule supporting the finite-panel claim boundary ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
- The local scan scores unwanted products in the supplied background, but it cannot claim completeness for an absent or incomplete background; the bounded ungapped scan is not a substitute for indexed whole-database search ([NCBI Primer-BLAST guidance](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/)).
- The species-specific path deliberately retains sites with a possible terminal 3′ mismatch for review and conservative gating. That site is reported as a potential off-target; it is not presented as proof that the polymerase will extend it, because terminal-mismatch behaviour depends on mismatch identity, neighbouring bases, enzyme and cycling conditions ([Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/)).
- The result must distinguish “not found in the checked background” from “specific”. For the species-specific branch, **any complete sequence-possible opposing-site product inside the versioned three-mismatch discovery envelope removes that candidate**. The thermodynamic serious/watch split remains a ranking aid for non-exclusivity assays and is not used to certify a weaker species-specific hit as safe. A rejected sequence-possible product is still not proof that the polymerase will amplify it experimentally; this is a conservative finite-panel contradiction rule ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/), [Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/)).
- The multiplex route carries an exclusion background per target and uses the same required-background gate. A multiplex set without those sequences must not quietly downgrade each target to ordinary PCR under a species-specific label ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).

## Extended specificity and coverage rules

Species-specificity is a claim about a defined target population and a defined non-target universe, not only about a low mismatch count. Published species-primer workflows validate both inclusivity and exclusivity in silico and in vitro, while eDNA work shows that unsampled taxa, unresolved taxonomy and intraspecific polymorphism can materially change the claim boundary ([SpeciesPrimer workflow](https://pubmed.ncbi.nlm.nih.gov/32110486/), [unsampled-taxa framework](https://pubmed.ncbi.nlm.nih.gov/38263813/), [Oncorhynchus marker study](https://pubmed.ncbi.nlm.nih.gov/26536367/)).

The current runtime therefore treats panel hashing as a reproducibility mechanism only. It now additionally **requires** `inclusivity_panel_provenance`, `background_panel_provenance`, and `species_panel_selection_rationale` for every species-specific request (including the multiplex path). The worker records these user-declared authorities but does not independently verify them; `biological_traceability_status=user-declared-provenance-recorded-not-independently-validated` and `diversity_coverage_status=not-computed-from-panel-hash` make explicit that a deterministic FASTA fingerprint plus a declaration still does not establish isolate/accession identity, taxonomic correctness, temporal/geographic/phylogenetic representativeness or population-frequency coverage. Those claims require traceable panel metadata and empirical validation outside the sequence worker. FDA nucleic-acid assay guidance similarly treats inclusivity as a challenge across relevant genetic diversity and exclusivity as a challenge against related/cross-reactive organisms, rather than as a property proven by one reference sequence ([FDA nucleic-acid analytical-reactivity example](https://www.fda.gov/medical-devices/guidance-documents-medical-devices-and-radiation-emitting-products/nucleic-acid-based-in-vitro-diagnostic-devices-detection-mycobacterium-tuberculosis-complex-respiratory)).

| Additional rule | Resolution for species-specific PCR | Evidence boundary |
| --- | --- | --- |
| Target diversity | Build the inclusivity panel from representative lineages, strains/isolates and known polymorphisms; one reference FASTA is not population coverage ([Oncorhynchus marker study](https://pubmed.ncbi.nlm.nih.gov/26536367/), [SpeciesPrimer workflow](https://pubmed.ncbi.nlm.nih.gov/32110486/)). | The engine can test only records actually supplied. |

## Vendor- and chemistry-specific specificity boundary

Species specificity is not supplied by a brand name or a primer score. The selected polymerase/master mix can change mismatch discrimination, while the inclusivity/exclusivity panel and measured controls define the claim scope; therefore the module reuses named endpoint/high-fidelity chemistry overlays without copying their values into the species-specific contract ([Stadhouders et al.](https://pubmed.ncbi.nlm.nih.gov/19948821/), [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).

Published validation shows why the result must report panel composition and validation design, not only a percentage. In a multicentre Salmonella study, selectivity was evaluated across hundreds of target and non-target strains, an internal amplification control was used to reveal inhibition or preparation failure, and the collaborative laboratory study reported different inclusivity/exclusivity outcomes from the extended strain panel. These are assay-specific observations, not universal acceptance thresholds, but they support explicit panel counts, control identity and interlaboratory status in the record ([Malorny et al.](https://pubmed.ncbi.nlm.nih.gov/12514007/)).

The severity model must keep mismatch identity and position separate from the total mismatch count. The primary mismatch studies show that two sites with the same count can have very different amplification effects, and that master mix and primer orientation can alter the magnitude; therefore the engine may prioritize a site for review, but the final exclusivity decision still belongs to a defined panel and a measured assay ([Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/), [Stadhouders et al.](https://pubmed.ncbi.nlm.nih.gov/19948821/)).

## Heavy-pass enrichment — pangenome and population-aware specificity

Species/strain specificity must be evaluated against the population actually relevant to the assay rather than a single representative reference. A 2026 pangenome workflow used strain-unique accessory genes to develop strain-specific qPCR assays and showed an important failure mode: a putatively unique candidate can still prove biologically non-unique and require target reselection. PCRStudio therefore treats pangenome uniqueness as **candidate evidence requiring explicit background search and empirical exclusivity**, not as a guarantee from orthogroup membership alone ([Scientific Reports 2026](https://www.nature.com/articles/s41598-026-41449-8)).

`MicrobiomePrime` provides a separate source-tracking precedent based on large community datasets. The study used `953` fecal/fecal-waste samples representing more than `50` mammal/bird species; `51` primer pairs were experimentally evaluated and `18` achieved `100%` specificity within that validation set. These values remain study-specific. The transferable design rule is to preserve the discovery population, non-target population, geography/source class and empirical validation panel with each marker/primer claim ([Water Research 2026](https://www.sciencedirect.com/science/article/pii/S0043135425018937)).

Population-aware records should retain `target_population`, `background_population`, release/retrieval date, geography/time boundary, marker-discovery method, in-silico specificity method and the empirical inclusivity/exclusivity panel. A result generated from a narrow local population must not be labeled globally species-specific without additional evidence ([MIQE molecular-assay guidance](https://pubmed.ncbi.nlm.nih.gov/32145632/)).

## Unresolved evidence gaps

**Internal audit findings:** The following are not claims that can be closed by the current sequence-only worker:

- No target taxon, intended sample matrix, reference-method comparator, marker locus, accession set or representative target/non-target panel was supplied for this module. A defensible marker choice and panel size therefore cannot be selected from this record alone; the required inputs are described by the [FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=) and [MacDonald & Sarre](https://pubmed.ncbi.nlm.nih.gov/27768246/).
- No evidence currently justifies turning the reported 3′ mismatch topology into a chemistry-specific amplification probability for the bound `taq-standard` endpoint profile, the actual primer sequences, selected annealing/cycling conditions or intended matrix. The primary mismatch studies show that identity, position, orientation and master mix can change the result ([Kwok et al.](https://pubmed.ncbi.nlm.nih.gov/2179874/), [Stadhouders et al.](https://pubmed.ncbi.nlm.nih.gov/19948821/)).
- No assay-specific wet-lab inclusivity/exclusivity panel, extraction blank, positive extraction control, NTC outcome, IAC design, matrix-spike data, LOD/LOD95%, repeatability, robustness, inter-laboratory result or orthogonal confirmation result is present. These omissions prevent `laboratory-verified` or diagnostic-specific claims ([FDA nucleic-acid guidance](https://www.fda.gov/media/121751/download?attachment=), [FDA Foods Program Guidelines](https://www.fda.gov/media/83812/download)).
- The local bounded scan has no externally documented database release, taxonomic curation record, genome/assembly completeness assessment, BLAST parameter record or proof that forward–forward and reverse–reverse alternatives were searched. It must not be reported as indexed whole-database specificity ([NCBI Primer-BLAST](https://www.ncbi.nlm.nih.gov/tools/primer-blast/primertool.cgi/primerinfo.html), [NCBI RefSeq](https://www.ncbi.nlm.nih.gov/refseq/)).
- The dedicated multiplex orchestrator now preserves each species-specific target's inclusivity/exclusivity evidence, requires one shared assay/reaction/named protocol/RT authority per physical tube, evaluates set-level oligo interaction badness, and applies an explicit readout-spacing model when one is selected. What remains unresolved is **empirical** cross-target competition, non-target co-template behaviour, matrix inhibition, abundance asymmetry and platform-specific multiplex sensitivity/specificity. The Phusion Plus manual's lower primer starting concentration for multiplex reactions is a chemistry adjustment, not evidence that a species panel is multiplex-validated ([Phusion Plus protocol](https://www.thermofisher.com/us/en/home/references/protocols/nucleic-acid-amplification-and-expression-profiling/pcr-protocol/phusion-pcr-protocol.html)).
- The record does not yet define the endpoint readout acceptance rule for band size, gel resolution, intensity, replicate concordance or sequence confirmation. The FDA BAM Cronobacter method’s screening-versus-culture-confirmation split shows why a positive amplification signal and an organism identity must remain separate claims ([FDA BAM Chapter 29 — Cronobacter](https://www.fda.gov/media/173834/download)).
