### Current runtime boundary (2026-09-04)

The `taq-standard` salt/Mg/dNTP/oligo tuple is now emitted with `context_role=primer-design-thermodynamic-screening-context`. PCRStudio does **not** promote the preset's generic cycling object to a per-pair annealing programme, and the UI/report state that these values exist to make Primer3 calculations reproducible rather than to reconstruct a supplier buffer. This distinction is necessary because even current routine-Taq guidance permits chemistry- and template-dependent variation in primer concentration, Mg²⁺, annealing temperature, cycle count and difficult-template handling ([NEB Taq M0273 protocol](https://www.neb.com/en-gb/protocols/taq-dna-polymerase-with-standard-taq-buffer-m0273), [NEB OneTaq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-onetaq-and-onetaq-hot-start-dna-polymerases)).

### Named Standard-PCR bench registry

The runtime now supports a curated, source-backed set of **bench/provenance overlays** without changing the shared sequence-ranking model: `neb-taq-m0273`, `neb-q5-hot-start-m0493`, `neb-q5u-hot-start-m0515`, `thermo-dreamtaq-hot-start-ep170x`, `thermo-phusion-plus`, `promega-gotaq-m300`, `thermo-platinum-superfi-ii`, four distinct OneTaq Hot Start Standard/GC/Quick-Load formulation branches, `pcrbio-hs-taq-mix-pb10-22`, `qiagen-alltaq-master-mix-203144`, `thermo-platinum-ii-taq-hot-start`, `toyobo-kod-one-kmm101`, plus the multiplex-only `neb-multiplex-pcr-m0284` branch. Every record returns `sequence_decision_impact=none` and `thermodynamic_model_impact=none`; the protocol may document cycling, fidelity, hot-start state, uracil/dUTP compatibility, product-end chemistry and difficult-template options, but PCRStudio does not reconstruct proprietary buffer thermodynamics from a product name ([NEB Q5 M0493 protocol](https://www.neb.com/en/protocols/pcr-using-q5-hot-start-high-fidelity-dna-polymerase-m0493), [NEB Q5U M0515 protocol](https://www.neb.com/en-us/protocols/pcr-using-q5u-hot-start-high-fidelity-dna-polymerase-neb-m0515), [Thermo Platinum SuperFi II MAN0018859](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/MAN0018859_Platinum_SuperFi_II_DNA_Pol_UG.pdf)).

For the `multiplex` modifier, a named Standard-PCR overlay is a **single tube-level choice**, not a per-target property. The Web multiplex form carries one shared `standardPcrProtocol`; the server consumes that public field only for `standard-pcr` and injects the same worker-side `standard_pcr_protocol` into every target. `not-selected` remains a legitimate design-only branch and emits no named bench protocol. Mixed per-target polymerases are not modeled as one physical reaction ([MIQE multiplex reporting guidance](https://pubmed.ncbi.nlm.nih.gov/40272429/)).

The registry is intentionally representative rather than exhaustive. Promega GoTaq M300 is executable because the current `9PIM300` protocol supplies a complete named reaction/cycling recipe; Green versus Colorless reaction buffer remains an explicit bench choice, and PCRStudio does not infer dUTP/UDG compatibility from generic Taq-family behavior when the reviewed M300 source does not state it. The registry distinguishes ordinary Taq-family 3′-dA products from blunt high-fidelity products and keeps Q5/Q5U uracil behavior separate. NEB's current Q5 protocol states that Q5 cannot incorporate dUTP and is not recommended for uracil-containing primers/templates, whereas Q5U is dUTP-tolerant, supports uracil-containing substrates, uses 2.0 mM Mg²⁺ in 1× Q5U Reaction Buffer and can be paired with thermolabile UDG when the actual carry-over-prevention workflow is recorded ([Q5 M0493](https://www.neb.com/en/protocols/pcr-using-q5-hot-start-high-fidelity-dna-polymerase-m0493), [Q5U M0515](https://www.neb.com/en-us/protocols/pcr-using-q5u-hot-start-high-fidelity-dna-polymerase-neb-m0515)). Q5U's separate damaged/bisulfite programme is **not** silently selected by an ordinary Standard-PCR request.

Difficult-template additives remain protocol-specific experiments. Q5 High GC Enhancer is not a universal buffer and NEB says it should be added with Q5 Reaction Buffer when other conditions have failed; Q5U permits up to 2% DMSO for certain difficult or long targets. Thermo Phusion Plus similarly has its own GC-enhancer guidance. These facts are retained as hand-off metadata, not converted into a rule such as `GC > X → add DMSO/enhancer`, because GC percentage alone does not identify the limiting reaction mechanism ([NEB Q5 M0493 protocol](https://www.neb.com/en/protocols/pcr-using-q5-hot-start-high-fidelity-dna-polymerase-m0493), [NEB Q5U M0515 protocol](https://www.neb.com/en-us/protocols/pcr-using-q5u-hot-start-high-fidelity-dna-polymerase-neb-m0515)).

The runtime also normalizes **carry-over and downstream-product provenance** across the named Standard-PCR branches. Selecting a dUTP-tolerant polymerase does not itself mean that carry-over prevention is active: dUTP use and a compatible UDG/pretreatment workflow must be recorded separately. `neb-taq-m0273` and `thermo-dreamtaq-hot-start-ep170x` are recorded as dUTP-capable but without built-in UDG; `neb-q5-hot-start-m0493` and `thermo-phusion-plus` are recorded as dUTP/uracil-incompatible; and `neb-q5u-hot-start-m0515` is the explicit uracil/dUTP-tolerant high-fidelity branch, again without inferring that UDG was actually used. Product-end provenance is likewise kept separate from primer design: Taq-family and DreamTaq branches expect 3′-dA products, whereas Q5/Q5U/Phusion Plus are blunt-end proofreading branches. These are downstream chemistry facts, not sequence-ranking bonuses. Current Thermo guidance for Phusion Plus (`MAN0025053`, Rev. B) identifies an **antibody-molecule-mediated hot-start** mechanism; the runtime records that product-specific mechanism rather than transferring it to other high-fidelity polymerases. NEB describes Q5 Hot Start as **aptamer-based**, so the runtime does not invent a more specific aptamer chemistry than the vendor states ([NEB Q5 M0493](https://www.neb.com/en/protocols/pcr-using-q5-hot-start-high-fidelity-dna-polymerase-m0493), [Thermo Phusion Plus protocol](https://www.thermofisher.com/us/en/home/references/protocols/nucleic-acid-amplification-and-expression-profiling/pcr-protocol/phusion-pcr-protocol.html)).

## Research question

**Internal research question.** What is the defensible default design for a conventional endpoint PCR pair, and which checks must be hard constraints, ranking signals, warnings, or post-design validation?

## Module-owned values and current implementation

**Internal module-resolution record.** This module resolves the following values for its profile and purpose layer:

- length 18–25 nt, optimum 20 ([PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/));
- Tm 57–63 °C, optimum 60 °C ([PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/), [Primer3 manual](https://primer3.org/manual.html));
- pair Tm difference ≤3 °C ([Primer3 manual](https://primer3.org/manual.html));
- GC 40–60% ([PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/));
- product 200–1000 bp under the default `general` purpose layer ([fragment-analysis guide](https://assets.thermofisher.com/TFS-Assets/GSD/Technical-Notes/fragment-analysis-guide-technote.pdf));
- maximum homopolymer run 4 ([Primer3 manual](https://primer3.org/manual.html));
- no hard 3′ GC clamp ([Onodera & Melcher](https://pubmed.ncbi.nlm.nih.gov/15488375/));
- maximum five 3′ bases containing GC: 5 (effectively unrestricted) ([Primer3 manual](https://primer3.org/manual.html));
- a low-weight empirical 3′-triplet prior used to rank ordinary endpoint-PCR candidates ([Onodera & Melcher](https://pubmed.ncbi.nlm.nih.gov/15488375/));
- no ambiguity bases in a designed oligo ([Primer3 manual](https://primer3.org/manual.html));
- thermodynamic hairpin, self-dimer, and pair-dimer evaluation delegated to the pinned Primer3 thermodynamic model/defaults unless a separately sourced, versioned assay profile provides explicit structure limits. The former project rule `tm_min - 10` was an unsourced heuristic and is not an executable hard gate.

These values are implementation facts, not yet a claim that every value is universally optimal. Their scientific starting points are the [PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/), the [Primer3 manual](https://primer3.org/manual.html) and the [fragment-analysis guide](https://assets.thermofisher.com/TFS-Assets/GSD/Technical-Notes/fragment-analysis-guide-technote.pdf); the exact resolution remains a project profile decision.

## Evidence gathered in this pass

### General PCR primer design

The open protocol review by Rychlik et al. / the NCBI-hosted PCR protocol describes the usual design envelope as 15–30 nt, approximately 40–60% GC, similar primer Tm, avoidance of 3′ complementarity, and avoidance of long homopolymers ([PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/)). It supports the current window as a conservative subset, but it does not by itself justify every hard threshold used by this project.

Primary experiments reinforce why the profile keeps annealing and concentration values scoped rather than universal. Rychlik et al. found that the optimum annealing temperature depends on the less-stable primer/template pair and the product, and that their calculated values agreed with experiment within 0.7 °C for the tested systems; they also reported that a progressively raised annealing temperature can improve synthesis of products shorter than 1 kb ([Rychlik et al., 1990](https://pubmed.ncbi.nlm.nih.gov/2243783/)). Wu et al. independently showed that primer length, base composition and annealing temperature jointly control amplification specificity and efficiency ([Wu et al., 1991](https://pubmed.ncbi.nlm.nih.gov/2012681/)). These studies support an explicit thermal-programme review, not a universal conversion from predicted Tm to one annealing temperature.

A separate systematic PCR study reported context-specific starting observations of approximately `0.1–0.2 µM` primers, magnesium below `2 mM`, about `25` cycles, longer extension for products above `1 kb`, and strong inhibition from some 3′ mismatches ([systematic PCR-parameter study](https://pubmed.ncbi.nlm.nih.gov/2313237/)). Because those values were measured on particular templates, primer sets and reaction conditions, the engine records them as historical evidence and validation candidates rather than replacing the selected polymerase/vendor protocol with them.

Source: [Polymerase Chain Reaction: Basic Protocol Plus Troubleshooting and Optimization Strategies](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/).

**Internal verification checklist.** Additional independent checks:

- National Academies BioWatch assay-development framework and specificity validation: [National Academies BioWatch framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)
- Thermo Fisher's fragment-analysis guide uses 200–1,000 bp as a practical standard-PCR product range and separates it from the shorter qPCR range; this supports the module default as an application-oriented starting point, not as a universal physical limit ([fragment-analysis guide](https://assets.thermofisher.com/TFS-Assets/GSD/Technical-Notes/fragment-analysis-guide-technote.pdf)).
- NEB general PCR optimisation guidance for denaturation, extension and final extension starting points ([Taq PCR optimisation](https://www.neb.com/en-us/protocols/taq-dna-polymerase-guidelines-for-pcr-optimization)).
- An observational analysis of successful published PCR primers found that 3-prime triplet recommendations conflict across sources and that a high GC 3-prime end can reduce specificity. It analysed 2,137 primers, found all 64 triplets in use with non-uniform frequencies, and recommends scoring a larger candidate pool rather than imposing one universal rule ([Onodera & Melcher](https://pmc.ncbi.nlm.nih.gov/articles/PMC7127618/)).

### Current project findings carried forward

**Internal implementation record.** The earlier Standard PCR pass measured four implementation facts. They are not literature claims; the scientific evidence and decision boundary are recorded below:

1. Pair-complementarity ceilings must follow the same structure ceiling as single-primer structures ([Primer3 manual](https://primer3.org/manual.html)).
2. Supplied variant coordinates cannot be represented safely as one static excluded interval because primer placement is strand- and geometry-dependent; Generation-1 therefore evaluates them after placement and rejects any candidate primer that overlaps a supplied coordinate. A coordinate alone is not enough evidence to invent a universal safe 3′ distance or mismatch-tolerance rule ([Kwok et al.](https://doi.org/10.1093/nar/18.4.999)).
3. Cross-primer dimer is useful both as a hard Primer3 gate and as a ranking signal among surviving pairs ([Primer3 manual](https://primer3.org/manual.html)).
4. Product composition should be reported rather than rejected by an unsupported extreme-window heuristic ([Chang et al.](https://doi.org/10.4238/2015.July.28.20), [Jensen et al.](https://doi.org/10.1371/journal.pone.0011024), [Sahdev et al.](https://doi.org/10.1016/j.mcp.2007.03.004)).

### Transcript-aware RT-PCR option

When the same engine is used for an RT-PCR workflow, `from_rna` records the chemistry but cannot infer exon structure after `U` has been normalised to `T`. The optional `exon_junctions` field therefore accepts zero-based boundaries between transcript bases; when present, every returned pair must have at least one primer crossing a supplied boundary. This is an explicit cDNA geometry filter, not evidence that the annotation is correct or that genomic DNA is absent. MIQE 2.0 recommends exon–exon-spanning primers/probes and/or intron-spanning amplicons when genomic carryover is a concern, while modern tools pair junction design with genomic alignment rather than guessing from a transcript string ([MIQE 2.0](https://pubmed.ncbi.nlm.nih.gov/40272429/), [ExonSurfer 2024](https://pubmed.ncbi.nlm.nih.gov/38867172/)).

Sources: [MIQE 2.0](https://pubmed.ncbi.nlm.nih.gov/40272429/) and [ExonSurfer 2024](https://pubmed.ncbi.nlm.nih.gov/38867172/).

### Deep branch audit: thermodynamics, chemistry, input and validation

Primer melting temperature is not a sequence-only constant. Nearest-neighbour thermodynamics depend on duplex sequence, salt and strand concentration, and different salt-correction models can yield different predictions; SantaLucia's nearest-neighbour parameterisation and the Owczarzy salt-correction work therefore support using Tm for pair matching while keeping the selected polymerase/buffer responsible for the annealing programme ([SantaLucia nearest-neighbour thermodynamics](https://doi.org/10.1073/pnas.95.4.1460), [Owczarzy salt correction](https://doi.org/10.1021/bi702363u), [Primer3 manual](https://primer3.org/manual.html)).

The module's `57–63 °C` and `≤3 °C` pair-difference values are consequently a deliberately narrow candidate envelope, not a universal PCR rule. The official NEB Taq guidance permits calculated primer Tm values of `42–65 °C` and pair differences within `5 °C`, while Phusion Plus allows a product-specific range and warns against pair differences over `10 °C`; these values are chemistry-specific overlays and must not be averaged into the Standard-PCR profile ([NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase), [Phusion Plus PCR protocol](https://www.thermofisher.com/us/en/home/references/protocols/nucleic-acid-amplification-and-expression-profiling/pcr-protocol/phusion-pcr-protocol.html)).

The most defensible Taq starting branch is also broader than the current search envelope: NEB describes routine primers as `20–30 nt`, `40–60%` GC, with `0.05–1.0 µM` of each primer (typically `0.1–0.5 µM`), `1.5–2.0 mM` Mg²⁺, `200 µM` of each dNTP, and `0.5–2.0 U` polymerase per `50 µL` reaction, ideally `1.25 U`. Higher primer or template concentrations and excessive cycling can increase nonspecific products, so the engine should report the selected branch rather than imply that the narrower profile is a biochemical minimum ([NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase)).

For routine Taq cycling, NEB gives an initial `95 °C` denaturation of `30 s` for most purified templates, `15–30 s` denaturation, `45–68 °C` annealing for `15–60 s`, `68 °C` extension at about `1 min/kb` (or `45–60 s` below `1 kb`) and a `5 min` final extension; it recommends `2–4 min` initial denaturation for difficult GC-rich templates and a gradient beginning about `5 °C` below calculated Tm when annealing requires optimisation. These are starting conditions for that Taq protocol, not a Standard-PCR universal programme ([NEB Taq protocol](https://www.neb.com/en-us/protocols/taq-dna-polymerase-with-standard-taq-mg-free-buffer-m0320), [NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase)).

Hot-start status is a chemistry and setup branch, not a primer-design property. NEB identifies nonspecific primed synthesis during reaction assembly as a source of unwanted products and recommends ice assembly, adding polymerase last and transferring to a preheated cycler, with hot-start polymerase as the next option; antibody-mediated DreamTaq Hot Start instead permits room-temperature setup and produces `3′-dA` overhangs while tolerating dUTP, so its cloning and carryover-contamination consequences must remain attached to the named product ([NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase), [DreamTaq Hot Start manual](https://www.thermofisher.com/TFS-Assets/LSG/manuals/MAN0015972_ThermoScientificDreamTaqHotStartDNAPolymerase.pdf), [Green & Sambrook hot-start protocol](https://pubmed.ncbi.nlm.nih.gov/29717052/)).

Q5 is not a drop-in Taq substitute. NEB's Q5 application note recommends starting at `62 °C` for stand-alone Q5 and `60 °C` for Q5 master mixes when a single annealing temperature is required, with `98 °C/30 s` initial denaturation, `25–35` cycles, `72 °C` extension at `20–30 s/kb` for complex genomic DNA or `10 s/kb` for simple/short templates, and `72 °C/2 min` final extension; the products are blunt-ended, and standard Q5 is not compatible with dUTP whereas Q5U is the uracil-compatible branch ([Q5 universal annealing application note](https://media.neb.com/m/5ee45964c1bea954/original/AppNote_Q5_UniversalAnnealing_Temp.pdf), [Q5 Hot Start protocol](https://www.neb.com/en/protocols/pcr-using-q5-hot-start-high-fidelity-dna-polymerase-m0493), [Q5U product page](https://www.neb.com/en-us/products/m0515-q5u-hot-start-high-fidelity-dna-polymerase)).

Phusion Plus and DreamTaq provide distinct input and difficult-template branches. Thermo's Phusion protocol gives `0.01–10 ng` plasmid, `5–100 ng` genomic DNA, `0.5 µM` primers as a starting value, `0.1–1.0 µM` as an adjustable range, and a GC enhancer for amplicons above `65%` GC; DreamTaq Hot Start gives `10 pg–1 µg` template and `0.1–1.0 µM` primers in a `50 µL` reaction. The values are product recipes, not evidence for a shared template mass or additive default ([Phusion Plus PCR protocol](https://www.thermofisher.com/us/en/home/references/protocols/nucleic-acid-amplification-and-expression-profiling/pcr-protocol/phusion-pcr-protocol.html), [DreamTaq Hot Start manual](https://www.thermofisher.com/TFS-Assets/LSG/manuals/MAN0015972_ThermoScientificDreamTaqHotStartDNAPolymerase.pdf)).

GC-rich rescue should be represented as an explicit experimental branch. In one primary study of a GC-rich FMR1 target, `1 M` betaine plus `5%` DMSO gave reproducible amplification, while other primary work found DMSO or betaine improved yield and specificity for particular synthetic GC-rich constructs; these results justify recording additives, target GC and the tested concentration, but not promoting either additive to an ordinary-PCR default ([GC-rich FMR1 study](https://pubmed.ncbi.nlm.nih.gov/23901197/), [Jensen et al.](https://doi.org/10.1371/journal.pone.0011024), [Musso et al.](https://doi.org/10.2353/jmoldx.2006.060058)).

Input amount is part of specificity and inhibition control. NEB's routine Taq guidance uses approximately `10^4` target copies for detection in `25–30` cycles and suggests `1 pg–10 ng` plasmid/viral template or `1 ng–1 µg` genomic template; it also warns that higher DNA concentrations reduce specificity. Independent work found that genomic DNA can inhibit conventional PCR through nonspecific primer interactions and that the effect depends on primer Tm/GC, annealing temperature and polymerase concentration, which supports exposing template class, mass and inhibition-control status rather than treating “no product” as a primer-only failure ([NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase), [Latham et al.](https://pubmed.ncbi.nlm.nih.gov/37083935/)).

Specificity evidence must identify the searched sequence universe. NCBI Primer-BLAST recommends selecting the smallest database likely to contain the target and an organism when appropriate, while using `nr` without an organism for broad coverage; a supplied-template/local scan cannot establish genome-wide exclusivity, and a gapped or indel-aware search is a separate requirement. The 3′ mismatch literature also shows that mismatch identity, position and sequence context change yield, so the module's placement-aware variant warning is defensible but cannot be reduced to one universal mismatch cutoff ([NCBI Primer-BLAST guide](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/), [Kwok et al.](https://doi.org/10.1093/nar/18.4.999), [3′ mismatch study](https://pmc.ncbi.nlm.nih.gov/articles/PMC3174695/)).

Validation must distinguish endpoint-PCR qualitative evidence from quantitative-PCR performance claims. Authoritative PCR performance guidance separates target positive controls, no-template controls, inhibition controls, reference materials, inclusivity/exclusivity panels, product readout and continuing quality assurance; ISO 20395 is explicitly scoped to qPCR and dPCR quantification, so its precision, linearity, LOD, LOQ and trueness requirements must not be imported as unqualified acceptance thresholds for this endpoint profile ([NCBI PCR performance standards](https://www.ncbi.nlm.nih.gov/books/NBK305481/), [NCBI PCR controls](https://www.ncbi.nlm.nih.gov/books/NBK305483/), [ISO 20395:2019](https://www.iso.org/standard/67893.html)).

For a conventional gel-readout assay, an internal amplification control is a conditional validation choice rather than an automatic primer-engine output: it is valuable when a negative sample result could reflect matrix inhibition, but it introduces competition and therefore needs its own compatibility study. A multicentre conventional-PCR validation of Salmonella used an internal amplification control, tested inclusivity/exclusivity panels and confirmed selected products by sequencing, illustrating the validation pattern without supplying a universal acceptance number for unrelated assays ([Salmonella multicentre PCR validation](https://pubmed.ncbi.nlm.nih.gov/12514007/)).

([Genet Mol Res 2015](https://doi.org/10.4238/2015.July.28.20)), Jensen et al. ([PLoS ONE 2010](https://doi.org/10.1371/journal.pone.0011024)) and Sahdev et al. ## Remaining boundary

The supplied-background scan is bounded and ungapped. It is not a mammalian genome-scale uniqueness proof and cannot see an off-target reachable through an indel ([NCBI Primer-BLAST guidance](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/)). The correct next step for that question is an explicit indexed or Primer-BLAST handoff; inventing a gap penalty here would overstate the result.

## Current assessment

The architecture is sound for ordinary endpoint PCR within the limits described by the [Primer3 manual](https://primer3.org/manual.html) and the [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/):

- Primer3 performs candidate generation under explicit hard constraints ([Primer3 manual](https://primer3.org/manual.html)).
- The reaction and purpose layers are applied before search, consistent with the need to keep chemistry-specific conditions separate from generic primer constraints ([NEB Taq optimisation](https://www.neb.com/en-us/protocols/taq-dna-polymerase-guidelines-for-pcr-optimization)).
- Internal software-contract rule: candidate diversity is handled after Primer3 so five near-identical pairs do not masquerade as five independent choices; this is an internal ranking policy, not a biological claim.
- Variant masking, accessibility, specificity, amplicon composition, and provenance are retained as report fields rather than being treated as proof of amplification ([National Academies BioWatch framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
- Internal software-contract invariant: the profile is attached before validation and execution so the saved-project and public design paths use the same preparation; this is not an external scientific claim.

## Open evidence questions

The 3′ GC-clamp question is resolved as a profile decision rather than a universal rule: Standard PCR now asks Primer3 for candidates with `gc_clamp=0`, then applies the complete Onodera & Melcher frequency table as a low-weight ranking prior ([Onodera & Melcher](https://pubmed.ncbi.nlm.nih.gov/15488375/), [Primer3 manual](https://primer3.org/manual.html)). Long-range, qPCR, dPCR, species-specific and RPA profiles keep their chemistry-specific terminal values. This is not a claim that any one terminal triplet guarantees amplification.

**Internal resolved operational boundaries.** The review closes the following as scope decisions, while preserving the separate need for experimental validation. The scientific basis and limits are cited in the parameter rows and evidence sections below ([Primer3 manual](https://primer3.org/manual.html), [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)):

- the effective `200–1000 bp` Standard PCR `general` range is a practical, overrideable application envelope supported by [Thermo Fisher's guidance](https://assets.thermofisher.com/TFS-Assets/GSD/Technical-Notes/fragment-analysis-guide-technote.pdf), not a universal biological limit;
- Primer3's template/library mispriming checks are not sufficient for a large-genome specificity claim. Primer-BLAST combines Primer3 with database search and global alignment against a selected database, so this bounded worker must issue an explicit handoff instead of upgrading a local result to genome-wide specificity ([Primer3 manual](https://primer3.org/manual.html), [NCBI Primer-BLAST guidance](https://www.ncbi.nlm.nih.gov/guide/howto/design-pcr-primers/), [Primer-BLAST publication](https://pmc.ncbi.nlm.nih.gov/articles/PMC3412702/));
- indel-bearing or bulge-bearing off-targets are outside the current validated model. Primary mismatch studies show that 3′ effects depend on mismatch identity, position and sequence context, so an ungapped clean result cannot be presented as indel-complete; the correct disposition is an explicit gapped-alignment/database handoff ([Effects of primer-template mismatches](https://pmc.ncbi.nlm.nih.gov/articles/PMC330356/), [3′-end mismatch study](https://pmc.ncbi.nlm.nih.gov/articles/PMC3174695/), [Primer-BLAST publication](https://pmc.ncbi.nlm.nih.gov/articles/PMC3412702/));
- empirical efficiency, precision, linearity, LOD/LLOQ and specimen performance are validation records rather than primer-design defaults, consistent with the [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/) and [ISO 20395:2019](https://www.iso.org/standard/67893.html);
- a single Tm-difference limit is not universal across polymerases and buffers. Primer3's thermodynamic calculation remains useful for candidate matching, but the selected chemistry profile must own the effective annealing programme and any polymerase-specific correction ([SantaLucia](https://doi.org/10.1073/pnas.95.4.1460), [Owczarzy et al.](https://doi.org/10.1021/bi702363u), [NEB Q5 annealing guidance](https://media.neb.com/m/5ee45964c1bea954/original/AppNote_Q5_UniversalAnnealing_Temp.pdf)).

**Still validation-only.** Accessibility is intentionally an optional local fold used for comparative scoring and reporting. A missing, timed-out, partial or failed fold is visible as unchecked and never becomes either a clean result or a hard refusal; a future hard gate would require target- and chemistry-matched calibration data ([ViennaRNA API](https://viennarna.readthedocs.io/en/latest/api_python.html)).

The terminal-triplet decision is closed as an implementation policy: all 64 unambiguous triplets are represented, the pair uses their geometric-mean frequency, and the result records the two triplets and their frequencies as a soft ranking component. The scientific interpretation remains limited because the supporting study is observational and not a target- and chemistry-matched wet-lab benchmark ([Onodera & Melcher](https://pubmed.ncbi.nlm.nih.gov/15488375/)).

Terminal-GC guidance is deliberately preserved as a branch conflict. Thermo's DreamTaq primer guidance advises avoiding more than `3` G/C residues at the 3′ end while, if possible, ending with G or C; the Onodera–Melcher analysis found that no single practitioner recommendation was entirely satisfactory and proposed empirical scoring instead. Standard PCR therefore keeps `gc_clamp=0` and `max_end_gc=5` as this module's software contract, while a named DreamTaq overlay may retain the vendor's terminal preference ([DreamTaq DNA Polymerase manual](https://assets.thermofisher.com/TFS-Assets/LSG/manuals/MAN0012036_DreamTaqDNAPolymerase_500U_UG.pdf), [Onodera & Melcher](https://pmc.ncbi.nlm.nih.gov/articles/PMC7127618/)).

The ordinary Taq dNTP setting also has a documented fidelity/yield trade-off: NEB reports `50–100 µM` each dNTP as a condition that can enhance fidelity while reducing yield, whereas higher concentrations can increase yield, particularly for long PCR, while reducing fidelity. This is a named Taq optimization axis and is not a reason to change the module's primer constraints ([NEB Taq optimisation](https://www.neb.com/en/tools-and-resources/usage-guidelines/guidelines-for-pcr-optimization-with-taq-dna-polymerase)).

## Extended rules from primary and official sources

The endpoint-PCR profile must not collapse “amplifiable in silico” and “correct product in the tube.” A defensible workflow keeps template identity, positive control, no-template control, product-size/identity evidence and contamination review as separate validation records; the National Academies BioWatch assay-development framework treats these as part of assay verification rather than as consequences of a primer score ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/), [PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/)).

| Additional rule | Resolution for Standard PCR | Evidence boundary |
| --- | --- | --- |
| Polymerase purpose | `taq-standard` is appropriate for an ordinary endpoint starting point; fidelity-sensitive cloning or sequence confirmation must select a polymerase-specific high-fidelity workflow rather than silently changing the interpretation of this profile ([NEB Taq optimisation](https://www.neb.com/en-us/protocols/taq-dna-polymerase-guidelines-for-pcr-optimization)). | Product fidelity and error rate are polymerase- and protocol-specific; the primer engine cannot certify them. |
| Annealing optimisation | Keep the predicted Tm and pair ΔTm as candidate constraints, then treat gradient/touchdown optimisation as an experimental plan tied to the selected polymerase and buffer ([Primer3 manual](https://primer3.org/manual.html), [NEB Taq optimisation](https://www.neb.com/en-us/protocols/taq-dna-polymerase-guidelines-for-pcr-optimization)). | A calculated Tm is not a measured optimum. |
| Product identity | A size-compatible product must still be checked by the declared readout and, when identity matters, by sequence or an independent assay geometry ([National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)). | A predicted amplicon sequence does not prove the sample contained that molecule. |
| Contamination control | NTC and positive-control outcomes must be recorded independently of the candidate's specificity score; a contaminated NTC invalidates the run rather than changing the primer ranking ([PCR protocol review](https://pmc.ncbi.nlm.nih.gov/articles/PMC4846334/)). | The engine can specify controls but cannot observe their outcome. |
| Variant handling | A supplied variant set is evidence about the declared records only. A 3′-proximal mismatch can affect extension, but position and sequence context prevent a universal mismatch cutoff ([Kwok et al.](https://doi.org/10.1093/nar/18.4.999)). | Population coverage and unseen variants require an explicit panel or external alignment. |

The Standard-PCR profile therefore remains a sequence-design and preflight profile. It is not the correct place to invent universal Mg²⁺, additive, cycle-count or yield values: those are coupled to polymerase, buffer, template and purpose and must be selected from the corresponding protocol or validated experimentally ([NEB Taq optimisation](https://www.neb.com/en-us/protocols/taq-dna-polymerase-guidelines-for-pcr-optimization), [National Academies BioWatch assay-development framework](https://www.ncbi.nlm.nih.gov/books/NBK305487/)).
