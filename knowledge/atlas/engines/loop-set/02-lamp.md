## Scope

LAMP is a coordinated isothermal primer set, not a conventional inward-facing pair. The engine designs the roles required by the selected LAMP geometry and assembles them into one set. It does not call Primer3 for a conventional pair ([Notomi et al.](https://doi.org/10.1093/nar/28.12.e63)).

The module owns the reaction family, geometry, role-specific lengths, concentrations, product/loop limits, readout and validation claims. Shared sequence intake, topology, safety and provenance rules are inherited from the engine contract where applicable; the separation follows the documented distinction between LAMP geometry, chemistry and readout ([Soroka, Wasowicz and Rymaszewska](https://doi.org/10.3390/cells10081931)).

## Geometry and module-owned choices

The request must name the supported geometry and record its role layout. The engine validates the relationship between the inner primers, outer primers, loop primers, amplicon span and outer gap before accepting a set. Empty means the selected geometry's documented default; it never means an unrelated flanking-pair default ([Notomi et al.](https://doi.org/10.1093/nar/28.12.e63)).

The module record must also carry the selected Bst-family chemistry, operating hold, role concentrations, target window, optional variant exclusions and readout. These values are not shared with RPA or ordinary PCR and must be resolved from the selected kit/protocol rather than inferred from a Primer3 Tm ([Soroka, Wasowicz and Rymaszewska](https://doi.org/10.3390/cells10081931)).

## Execution contract

```text
request
  → typed target/window and ambiguity validation
  → selected geometry and reaction resolution
  → geometry feasibility check
  → role candidate enumeration
  → inner/outer and loop-role assembly
  → supplied-background and intended-product checks
  → set ordering and thinning
  → role-labelled oligos, isothermal protocol, validation plan and provenance
```

The engine must refuse impossible geometry by naming the violated relation. It must not make a valid-looking set by silently dropping a role or changing a user-supplied geometry ([Notomi et al.](https://doi.org/10.1093/nar/28.12.e63)).

## Output and claim boundary

Every set reports role identity and orientation, coordinates, sequence, geometry spans, reaction/cycling resolution, specificity scope, structure and interaction checks, warnings, validation obligations and tool provenance. These output fields separate a designed primer set from a measured detection result ([Soroka, Wasowicz and Rymaszewska](https://doi.org/10.3390/cells10081931)).

The result is not a guarantee of turbidity, fluorescence, colour, lateral-flow signal, time-to-positive, non-target exclusion or clinical performance. Probe and labelled-readout formats need typed chemistry and ordering metadata; plain primer text must never be presented as a finished probe. The boundary is required because LAMP readout chemistry is assay-specific ([Soroka, Wasowicz and Rymaszewska](https://doi.org/10.3390/cells10081931)).

## Vendor protocol overlay: NEB WarmStart LAMP Kit E1700

The runtime exposes E1700 as an explicit `lamp_protocol` choice. The default `not-selected` state emits no vendor protocol object and therefore does **not** invent a bench hold, reaction volume or primer concentration. LAMP design/structure diagnostics may still use their own separately versioned reference temperatures, but those are computational-model conditions rather than wet-lab incubation instructions. Selecting `neb-e1700` returns the six final primer concentrations, `25 µL` reaction volume, `65 °C / 30 min` incubation and optional `>80 °C / 5 min` inactivation as one kit-bound record; it never merges those values into another LAMP formulation ([NEB WarmStart LAMP Kit E1700 manual](https://www.neb.com/en/-/media/nebus/files/manuals/manuale1700.pdf?hash=F6CF27E9481EED00312FA90721209AA2&rev=95f0f9cee6c14de8b1c6f90a41392db7)).

NEB's E1700 protocol gives one concrete six-primer mix that must remain explicitly tied to that kit: final concentrations of `1.6 µM` for FIP and BIP, `0.2 µM` for F3 and B3, and `0.4 µM` for Loop F and Loop B. The protocol describes a nominal `25 µL` reaction and allows the reaction volume to be rescaled; these are vendor instructions, not engine-wide LAMP constants ([NEB WarmStart LAMP Kit E1700 protocol](https://www.neb.com/en/protocols/warmstart-lamp-kit-dna-rna-protocol-e1700?pdf=true)).

The runtime exposes these fields through a **named protocol registry**, not through an E1700-only special case. A protocol object is emitted only for the selected reviewed overlay and keeps its own `kit_id`, primer-role concentrations/amounts, reaction scale, thermal authority, substrate support, carry-over branch and readout context. Values from E1700 are never combined with a temperature, readout or dry-formulation rule borrowed from another Bst chemistry ([NEB WarmStart LAMP Kit E1700 protocol](https://www.neb.com/en/protocols/warmstart-lamp-kit-dna-rna-protocol-e1700?pdf=true)).

PCRStudio now exposes a **named protocol overlay** only when the public vendor record is specific enough to preserve a coherent reaction identity (primer-role concentrations or amounts, reaction scale, time/temperature authority, substrate support and readout/carry-over context). The overlay is bench/provenance context only: `sequence_decision_impact = none` is a release invariant, so choosing a kit cannot change genomic candidate enumeration, geometry, Tm eligibility or specificity ranking ([NEB WarmStart LAMP Kit E1700 protocol](https://www.neb.com/en/protocols/warmstart-lamp-kit-dna-rna-protocol-e1700?pdf=true)).

Nippon Gene's current NE6041/NE6043 manual is a different complete master-mix identity rather than an enzyme-only matrix: the `25 µL` recipe uses final FIP/BIP `1.6 µM`, F3/B3 `0.2 µM`, LoopF/B `0.8 µM` and `60–68 °C / 30 min`. The dry LMP207 product is a separate runtime identity: its current package insert specifies `60–67 °C` for `30–60 min`, `80 °C / 5 min` or `95 °C / 2 min` deactivation, and the same per-reaction FIP/BIP `40 pmol`, F3/B3 `5 pmol`, loop `20 pmol` starting amounts; it also states that RNA use requires prior cDNA synthesis ([Eiken LMP207 package insert](https://loopamp.eiken.co.jp/en/uploads/dna_d_insert.pdf)).

LMP247 is not an alias for LMP207. Its official dry-reagent insert accepts **RNA or DNA**, includes reverse transcriptase for one-step RT-LAMP and calcein for fluorescent/visual detection, retains the `25 µL` / `40/5/20 pmol` primer preparation, and keeps the assay range at `60–67 °C` for `30–60 min`; the insert explicitly says the optimum must be examined for the designed primer set. PCRStudio therefore stores the range rather than converting the control condition (`62.5 °C / 35 min`) into a universal sample hold ([Eiken LMP247 product](https://loopamp.eiken.co.jp/en/product/cat-102/rna_dna_e.html), [LMP247 package insert](https://loopamp.eiken.co.jp/en/uploads/rna_dna_insert.pdf)).

### Runtime scenario identities versus boundaries that remain fail-closed

R15 retains the source-backed vendor/formulation and conditional numeric branches and adds canonical authority, fixed-primer/mutation anchors, staged core→loop design, screening cohorts and ordered source-backed thermal stages, while preserving the parts that cannot yet be represented faithfully; the branch boundaries follow the source-specific vendor records rather than a generic LAMP abstraction ([NEB LAMP overview](https://www.neb.com/en/applications/dna-amplification-pcr-and-qpcr/isothermal-amplification/loop-mediated-isothermal-amplification-lamp), [Eiken LAMP principles](https://loopamp.eiken.co.jp/en/lamp/)):

- **OptiGene ISO-004/ISO-001 families.** Liquid DNA/RT, direct KOH Lyse & LAMP, dried and lyophilized identities are now explicit runtime choices with substrate/formulation/direct-matrix validation. Published concentration ranges remain evidence unless an exact source-bounded override envelope exists; selecting OptiGene does not authorize arbitrary bench tuning.
- **OptiGene ISO-001Tin / HD-LAMP.** `optigene-iso001tin` is retained as a DNA chemistry identity, but an optional `95 °C / 5 min` preheat followed by an isothermal phase is a multi-stage thermal topology. PCRStudio records that evidence and does not silently encode the preheat as an ordinary one-hold LAMP run.
- **Thermo Fisher dry/lyo branches.** `thermo-a56656` is executable as a DNA-only assembled-enzyme authority and remains distinct from the `thermo-a5180x` SuperScript IV master mix. Product-specific Dry-Ready RT-LAMP formulation/thermal evidence is not collapsed into either identity.
- **Meridian Bioscience.** General, direct-matrix, liquid, lyophilized and air-dryable product identities are represented separately. Direct-sample authority is exact-product and matrix-specific; for example, `meridian-mdx126` allows the reviewed blood/plasma/serum branch and liquid/air-dryable formulations, but does not make other LAMP mixes generically blood-tolerant or air-dryable.
- **NEB assembled-enzyme branches.** `neb-m0275`, `neb-m0537`, `neb-m0538`, `neb-m0374` and `neb-m0402-m0439-rt` are runtime assembled-enzyme authorities. Their buffer/Mg²⁺/enzyme semantics are kept separate from complete master mixes; only explicitly typed optimization envelopes can be overridden.
- **Takara RR385.** `takara-rr385` is a DNA/RNA fluorescence branch with TB Green, UNG and reviewed melt/denaturation confirmation. Inorganic pyrophosphatase makes pyrophosphate-turbidity detection a hard incompatibility.
- **Modified reporter topology remains planned/fail-closed.** Sequence-specific probe, multiplex modified-primer/probe, lateral-flow modified-primer, DARQ/QUASR-like and related labeled-oligo branches require typed modified-oligo manufacturing and validation semantics; they are not approximated by an ordinary dsDNA readout flag.

The boundary is intentional: a vendor or product name is executable only to the extent that PCRStudio can preserve its source-bounded substrate, formulation, specimen, readout and thermal semantics without inventing missing chemistry; this follows the vendor-specific protocol authority used throughout the registry ([NEB WarmStart LAMP](https://www.neb.com/en/protocols/warmstart-lamp-kit-dna-rna-protocol-e1700?pdf=true), [Eiken LAMP products](https://loopamp.eiken.co.jp/en/product/)).

### R15 design-stage and topology boundary

Classic Loop Set now supports `integrated`, `core-first` and `add-loops` stages; exact F3/B3/FIP/BIP/LF/LB anchors; and mutation-position anchoring on explicitly selected inner-primer ends. Mutation anchoring constrains geometry only and does not synthesize a universal secondary mismatch or claim wet-lab allele discrimination. The result also records a deterministic 2–4-set empirical screening cohort without changing primary ranking. The PrimerExplorer V5 public-rule profile uses AT-rich `<=45%`, Normal `>45% and <60%`, and GC-rich `>=60%`; PCRStudio does not claim the proprietary PrimerExplorer search/ranking algorithm. Gen-1 classic LAMP remains linear-target only; circular origin-spanning design fails closed rather than wrapping coordinates heuristically ([Notomi et al.](https://doi.org/10.1093/nar/28.12.e63)).

Vazyme RP712 and Hyasen HYB413/HYB414/HYB315 are current named product identities in R15. Hyasen public instructions support exact admitted 50 µL/primer/program arithmetic. RP712 retains the public 30-minute timing claim but keeps the exact transferable reagent-volume recipe unresolved because it is not snapshotted in the current public authority ([Vazyme LAMP kit documentation](https://www.vazyme.com/product/269.html)).

### Eiken calcein/readout boundary

Eiken's separate Loopamp Fluorescent Detection Reagent `LMP221` is a **readout chemistry**, not a primer-design rule. The reagent uses calcein/manganese chemistry and is added before amplification to compatible Loopamp DNA/RT-LAMP reagents. Its insert warns that chelating buffers such as TE, and high Ca/Zn/Fe content, can disturb fluorescence interpretation. PCRStudio therefore records Eiken fluorescence as protocol/readout provenance and does not translate it into a sequence score, universal fluorescence threshold or generic sample-compatibility claim ([Eiken LMP221](https://loopamp.eiken.co.jp/en/product/cat-102/fd_e.html)).

### Direct-sample and pH-colorimetric boundary

NEB's M1800/M1804 phenol-red workflows are deliberately low-buffer systems, so acidic or strongly buffered inputs can alter the starting colour independently of amplification; that is a chemistry-level compatibility warning and belongs with the selected readout/protocol, not primer ranking. More specific statements such as SDS inhibition, tolerated non-ionic detergent levels or guanidine limits come from named direct-sample workflows (for example the NEB SARS-CoV-2 rapid colorimetric protocol) and are **not** promoted to universal M1800/M1804 thresholds. Fully buffered multi-purpose mixes such as M1708/E1708 are a different sample-compatibility branch ([NEB M1800 protocol](https://www.neb.com/en/protocols/warmstart-colorimetric-lamp-2x-master-mix-typical-lamp-protocol-m1800), [NEB M1804 protocol](https://www.neb.com/en/protocols/warmstart-colorimetric-lamp-2x-master-mix-with-udg-typical-lamp-protocol-neb-m1804), [NEB M1708 product](https://www.neb.com/en-us/products/m1708-warmstart-multi-purpose-lamp-rt-lamp-2x-master-mix-with-udg), [NEB direct-sample SARS-CoV-2 protocol](https://www.neb.com/en/protocols/sars-cov-2-rapid-colorimetric-lamp-detection-assay-protocol-neb-e2019)).

### Secondary chemistry and non-template-amplification adjunct boundary

PCRStudio does not translate generic reaction additives into sequence-ranking rewards. NEB's current LAMP optimization guidance uses high Mg²⁺/dNTP concentrations as formulation starting points and explicitly says to omit betaine unless a demonstrated assay-specific benefit exists. Likewise, guanidine concentrations reported in named rapid colorimetric/direct-sample workflows stay tied to those workflows rather than becoming an engine-wide optimization knob. This prevents a chemistry tweak from being misrepresented as an in-silico specificity improvement ([NEB LAMP optimization guidance](https://www.neb.com/en-gb/-/media/nebuk/files/expressions-newsletters/neb_uk_expressions_jun_24.pdf?rev=6ae0b72075984c45ba2b898d7f9e18e8&sc_lang=en-gb)).

NEB also documents **Tte UvrD Helicase (M1202)** as an optional chemistry adjunct for non-template amplification. Its E1700 protocol adds `10–20 ng` UvrD to a `25 µL` reaction while retaining the ordinary `1.6/0.2/0.4 µM` primer concentrations; NEB's FAQ recommends `10 ng` with E1700 and gives polymerase-dependent titration ranges. This is assay-dependent mitigation: PCRStudio records it as a future typed additive/provenance branch and does not use UvrD availability to excuse poor primer-set geometry, incomplete specificity evidence or NTC failure ([M1202 protocol](https://www.neb.com/en-us/protocols/protocol-for-lamp-reactions-with-tte-uvrd-helicase-m1202), [NEB UvrD FAQ](https://www.neb.com/faqs/how-do-i-use-tte-uvrd-helicase-for-reducing-non-template-amplification-in-lamp-reactions)).

A 2026 *Analytica Chimica Acta* study adds a distinct experimental path: non-template `SCAN` analysis identified at least one **initiator inner primer (IIP)** in each representative set, and unamplified blocker oligos targeting F1c/B1c of the IIP delayed non-specific amplification; shortened `-3`/`-6` blockers were explored to balance suppression and desired-reaction efficiency. This is promising evidence, but it creates additional assay-selected oligos and empirical screening state. Gen-1 therefore keeps IIP-SCAN/Blocker-LAMP in the modified-oligo watchlist rather than fabricating blocker sequences from an ordinary FIP/BIP result ([Mo et al. 2026](https://pubmed.ncbi.nlm.nih.gov/41526128/)).

### Multiplex, modified-readout and linker boundaries

Gen-1 remains a **simplex LAMP primer-set engine**. Multiplex LAMP generally requires sequence-specific fluorogenic probes, modified primers or other target-coded detection chemistry; the 2024 methodological review explicitly treats DARQ-LAMP and related methods as separate multiplex strategies rather than ordinary six-primer LAMP ([Crego-Vicente et al. 2024](https://pubmed.ncbi.nlm.nih.gov/38928080/)). PCRStudio therefore does not manufacture DARQ/QUASR/lateral-flow oligos from plain LAMP primer output. Such formats need a future typed modification/probe layer with its own ordering and validation contract.

A 2023 study also tested **dual-priming oligonucleotide (DPO)** architecture in place of ordinary F3/B3 outer primers and reported comparable overall assay performance with greater temperature stability in that specific Listeria assay. DPO is not merely another DNA sequence string: its two priming segments are separated by a poly-dI linker and have distinct priming roles. PCRStudio therefore records DPO as an experimental modified-outer-primer architecture rather than adding a misleading `DPO on/off` flag to the current F3/B3 generator; adoption would require explicit molecule topology, manufacturing and structure/specificity validation ([Lamas et al. 2023](https://pubmed.ncbi.nlm.nih.gov/37167680/), [DPO architecture](https://pubmed.ncbi.nlm.nih.gov/17287288/)).

The FIP/BIP junction linker remains `none` by default with `TTTT` as an explicit research variant. A direct linker study found sequence-dependent performance and a favourable poly-T trend in its tested assay, but a multicentre SARS-CoV-2 RT-LAMP evaluation found `TTTT` failed to improve or impaired `6/7` evaluated primer sets. Therefore no linker is promoted to a universal hard preference, and polyA/polyG/polyC/polyI are not added as casual menu options without assay-specific validation ([multicentre RT-LAMP assessment](https://pmc.ncbi.nlm.nih.gov/articles/PMC9094544/)).

## Vendor and method overlays: Eiken and Thermo Fisher

Eiken's standard LAMP procedure defines the four-primer DNA set as FIP, F3, BIP and B3, with strand-displacing polymerase, dNTPs and reaction buffer; RNA templates require reverse transcriptase in addition to the DNA-LAMP reagents. The stated operating window is `60–65 °C` for `15 min–1 h`, and Eiken reports that adding Loop Primer can reduce amplification time to one-third to one-half of the no-loop-primer procedure, with amplification achievable within `30 min` in its described rapid workflow ([Eiken LAMP standard procedures](https://loopamp.eiken.co.jp/en/lamp/0207.html), [Eiken Loop Primer guidance](https://loopamp.eiken.co.jp/en/lamp/0204.html)).

Eiken's primer-preparation guidance gives a concrete Loopamp primer-mix starting point: prepare each primer stock at `100 pmol/µL`, then place per reaction FIP/BIP at `40 pmol` each, F3/B3 at `5 pmol` each and Loop Primer F/B at `20 pmol` each; it recommends aliquoting the mix, for example into `10`-reaction portions, and storing it at `−20 °C` ([Eiken primer preparation](https://loopamp.eiken.co.jp/en/lamp/0209.html)). These amounts are a named Eiken preparation example and must not replace a selected kit's final-concentration table.

Thermo Fisher's Dry-Ready RT-LAMP application note provides a second, chemistry-specific numerical record. Its `25 µL` control reaction uses `1×` buffer, `8 mM` MgCl₂, `1.4 mM` of each dNTP, `1.6 µM` each FIP/BIP, `0.2 µM` each F3/B3, `0.4 µM` each LoopF/LoopB, `0.24 U/µL` Bst polymerase and a template input of `4` or `40 copies/µL`; the dry mix is initially assembled as a `10 µL` mix and reconstituted with `25 µL` solution containing template. The note incubates at `65 °C` for `15–25 min`, with `20 min` as the initial condition and `5 min` increments used when detection is unreliable, followed by `95 °C / 5 min` inactivation ([Thermo Dry-Ready RT-LAMP application note](https://documents.thermofisher.com/TFS-Assets/BID/Application-Notes/detection-air-dried-lamp-app-note.pdf)). Validation evidence also needs a statistical endpoint, not only a single positive dilution. A primary LAMP evaluation defines the C95 LoD as the concentration at which `95%` of tested samples are positive, using serial `1:5` dilutions tested in duplicate, and reports an assay-specific estimate of about `40 copies/reaction`; that number is a study result, not a general LAMP LoD ([Rickettsia typhi LAMP LoD study](https://journals.asm.org/doi/10.1128/jcm.02786-13)). For reproducibility, a multiplex LAMP validation example tested `8` concentration levels, a `13`-organism non-target panel, `3` independently prepared reagent batches across `3` days with `3` replicates per batch, and used a `60 min` cutoff; these dimensions are a defensible validation template, not universal sample-size requirements ([CDC/ASM TPHD-LAMP validation](https://wwwnc.cdc.gov/eid/article/26/2/19-0505_article)).

## Current vendor overlay: NEB Bst-XT WarmStart M9204

NEB now publishes a separate Bst-XT WarmStart DNA Polymerase (`M9204`) LAMP/RT-LAMP protocol, so this branch must remain distinct from the existing E1700, M0402 and E1708 records. The standard `25 µL` setup contains `2.5 µL` 10X Bst-XT buffer (`1X`, contributing `2 mM` MgSO4), `1.0 µL` of `100 mM` MgSO4 (`4 mM` added; `6 mM` total), `3.5 µL` of `10 mM` dNTP mix (`1.4 mM` each), `2.5 µL` 10X LAMP primer mix, and `1 µL` Bst-XT (`8 U`, `320 U/mL`). For RNA targets, `0.5 µL` WarmStart RTx contributes `7.5 U` (`300 U/mL`). The protocol uses target input above `10 copies` and incubation at `65 °C` for `20 min` ([NEB Bst-XT WarmStart M9204 protocol](https://www.neb.com/en/protocols/loop-mediated-isothermal-amplification-lamp-protocol-using-bst-xt-warmstart-neb-m9204)).

The same current protocol defines optimization ranges rather than universal defaults: Mg2+ can be titrated up to `8 mM` final, Bst-XT from `320–600 U/mL`, and reaction temperature across `50–70 °C`. For carry-over prevention it permits `0.7 mM` dUTP plus Thermolabile UDG at `20 U/mL`, noting that Mg2+ up to `8 mM` can be beneficial in that branch. Intercalating fluorescent dye is used at `0.1–1X`. If products will be opened/manipulated after amplification, NEB advises a separate post-amplification area and allows enzyme inactivation above `80 °C` for `5 min`. These values are M9204-specific and must not overwrite E1700/M0402/E1708 chemistry ([NEB Bst-XT WarmStart M9204 protocol](https://www.neb.com/en/protocols/loop-mediated-isothermal-amplification-lamp-protocol-using-bst-xt-warmstart-neb-m9204)).

The glycerol-free successor/parallel formulation `M9205` has its own current protocol and is therefore a separate selectable overlay rather than an undocumented alias of M9204. It retains the `25 µL`, `1.6/0.2/0.4 µM`, `6 mM` total MgSO₄, Bst-XT `8 U` (`320 U/mL`) and `65 °C/20 min` starting reaction, but explicitly requires **glycerol-free** WarmStart RTx `M0439` at `7.5 U` (`300 U/mL`) for RNA targets and identifies the Bst-XT buffer as lyo-compatible. The same source keeps dUTP `0.7 mM` + thermolabile UDG `20 U/mL` optional, not built-in. PCRStudio records this formulation distinction without claiming that lyo-compatible components make an arbitrary primer assay a validated lyophilized product ([NEB M9205 protocol](https://www.neb.com/en/protocols/2025/03/18/loop-mediated-isothermal-amplification-lamp-protocol-using-bst-xt-warmstart-dna-polymerase-glycerol-free)).

## Deep-search enrichment — Bst-XT master-mix generation and adjacent LAMP chemistries

NEB now provides a distinct Bst-XT master-mix branch, `M1712`, that must not be collapsed into the standalone Bst-XT `M9204` enzyme record. M1712 is a `2×` fully buffered LAMP/RT-LAMP mix containing Bst-XT WarmStart DNA Polymerase, WarmStart RTx Reverse Transcriptase, dUTP and thermolabile UDG for carryover-contamination control. NEB lists a broad optimal-temperature envelope of `50–70 °C` for this Bst-XT formulation and the protocol uses a `65 °C` heating-device starting point. The current `25 µL` protocol uses `12.5 µL` M1712, `2.5 µL` 10× LAMP primer mix, optional intercalating dye at `0.5×`, template reported as `>10 copies`, and water to volume; NEB describes amplification in under `20 min` as a product/protocol capability and strongly recommends a no-template control ([NEB M1712 product](https://www.neb.com/en/products/m1712-bst-xt-warmstart-multi-purpose-lamp-rt-lamp-2x-master-mix-with-udg), [NEB M1712 protocol](https://www.neb.com/en/protocols/bst-xt-warmstart-multi-purpose-lamp-rt-lamp-2x-master-mix-with-udg-protocol-neb-m1712)).

Two patent families are retained as **adjacent architecture evidence**, not as validated runtime defaults. WO2017136387A1 describes RNase-H2-cleavable blocked LAMP primers/probes intended to reduce primer-dimer formation and add cleavage-dependent specificity; WO2021091487A1 describes LAMP coupled to a recyclable/cycling probe whose RNA/abasic cleavage generates repeated fluorescence signal. These chemistries alter primer/probe topology and enzyme requirements, so they belong in the atlas/watchlist but must not be silently mapped onto ordinary unmodified LAMP primers ([WO2017136387A1](https://patents.google.com/patent/WO2017136387A1/en), [WO2021091487A1](https://patents.google.com/patent/WO2021091487A1/en)).

### Current NEB LAMP Primer Design Tool geometry and formulation branch

The current NEB technical note adds a more complete, internally coherent design-tool branch than the earlier loop-Tm benchmark alone. For the named tool, the ideal F1c/B1c, F2/B2 and F3/B3 **region** lengths are `18–22 bp`; the F2–B2 amplified region is targeted to `120–160 bp`; and the F2–F3 spacing is described as generally `15–60 bases` with `40–60` preferred. The tool's default Tm calculation assumes `50 mM Na+` and `8 mM Mg2+`, with F1c/B1c and loop regions near `64–66 °C` and F2/B2/F3/B3 near `59–61 °C`. It also applies a terminal-`6 bp` end-stability rule of ΔG `< −4 kcal/mol`. These are **NEB-tool source-scoped design settings**, not universal LAMP gates ([NEB LAMP Primer Design Technical Note](https://media.neb.com/m/cc0bbc21ec612a7/original/LAMP_TechNote_0425.pdf)). PCRStudio's current region-Tm values are calculated with the separately documented PrimerExplorer V5 reference (`50 mM Na+`, `4 mM Mg2+`), so the NEB `64–66 °C` loop-primer preference is retained as evidence metadata but is **not used as an active ranking penalty** in Gen-1; cross-model temperature values are not treated as numerically interchangeable.

The same source ties the standard six-primer final mix to FIP/BIP `1.6 µM`, F3/B3 `0.2 µM`, and LF/LB `0.4 µM`, and recommends PAGE or HPLC purification for FIP/BIP while ordinary desalting is sufficient for screening the shorter primers. This manufacturing guidance is retained with the named LAMP workflow; it does not imply that all other vendors or modified LAMP oligos use the same purification rule ([Notomi et al.](https://pubmed.ncbi.nlm.nih.gov/12136105/)).

The note also documents a deliberately non-default long-amplicon branch. In its benchmark, F2–B2 distances above `160 bp` could slow detection by as much as `8 min` and reduce sensitivity; published longer LAMP products in the cited context (`262–945 bp`) required further optimization including `40–300 min` incubation, `0.5×/0.25×` primer concentration variants, `58–66 °C`, and additives. PCRStudio records this as evidence that long LAMP can exist **outside the default design window**, not as permission to relax the normal geometry without re-optimization and validation ([NEB LAMP Primer Design Technical Note](https://media.neb.com/m/cc0bbc21ec612a7/original/LAMP_TechNote_0425.pdf)).

### Carry-over contamination boundary

LAMP produces a large amount of amplified DNA, so opening a completed reaction for gel, colour or downstream handling creates a carry-over contamination risk. Published LAMP contamination work reports that a uracil-DNA-glycosylase strategy or a mineral-oil overlay can reduce carry-over under the tested assay conditions; the prevention method is therefore a protocol choice, not a consequence of the primer geometry ([Elimination of contamination in LAMP](https://pubmed.ncbi.nlm.nih.gov/33612764/)).

The current module does not silently replace dTTP with dUTP or enable UDG. A future carry-over overlay must name the polymerase/kit compatibility, nucleotide substitution, UDG amount and inactivation step together; otherwise the result remains `not selected` and the validation plan must keep setup/detection separation and no-template controls explicit ([Elimination of contamination in LAMP](https://pubmed.ncbi.nlm.nih.gov/33612764/), [NEB WarmStart LAMP Kit E1700 manual](https://www.neb.com/en/-/media/nebus/files/manuals/manuale1700.pdf?hash=F6CF27E9481EED00312FA90721209AA2&rev=95f0f9cee6c14de8b1c6f90a41392db7)).

## PCRStudio Generation-1 advanced design contract — 2026-09-02

### Versioned geometry rather than silent rule drift

The executable engine exposes two named geometry authorities. `primerexplorer-v5-compat` remains the default compatibility profile and preserves the reviewed PrimerExplorer V5 envelope. `pcrstudio-evidence-2026` is a separate evidence-composite profile: it keeps the accepted F2–B2 validity envelope while adding newer source-scoped preferences and a broader reviewed outer-primer search window. Selecting the advanced profile is explicit and is recorded in result provenance; literature updates do not silently change old runs. PrimerExplorer defines F2–B2, loop-region, F2–F3/B2–B3 and F1c–B1c distances as distinct geometry concepts, so PCRStudio keeps them separate ([PrimerExplorer V5 manual](https://primerexplorer.eiken.co.jp/e/v5_manual/02.html)). The current NEB technical note supplies newer design-tool evidence such as a `120–160 bp` preferred F2–B2 region, F2–F3/B2–B3 distances of `15–60 bases` with `40–60` highlighted as optimum, and loop-primer Tm around `64–66 °C`. PCRStudio activates the geometry preferences on the Evidence-2026 profile, but keeps the loop-Tm guidance documentation-only until a matching versioned NEB thermodynamic model exists; none of these are retroactive universal LAMP laws ([NEB LAMP Primer Design Technical Note](https://media.neb.com/m/cc0bbc21ec612a7/original/LAMP_TechNote_0425.pdf)).

### Inner-primer molecular identity and linker boundary

PCRStudio distinguishes the target-derived F1c/B1c tail from an optional synthetic FIP/BIP junction linker. The compatibility default is no synthetic linker; `TTTT` is available as an explicit research/evidence-backed variant. If selected, the linker is included in full ordered-oligo hairpin/dimer analysis and ordering provenance but is never searched against the genome. Experimental evidence shows that FIP/BIP linker sequence can materially affect LAMP performance and that thymine linkers outperformed no-linker in one studied assay; this does not establish `TTTT` as universally superior ([Talanta 2023](https://doi.org/10.1016/j.talanta.2023.124642)).

### Set-level structural risk

After hard role/geometry feasibility, PCRStudio performs a bounded second-stage review of the molecules that will actually be ordered. It records hairpin, self-dimer, all cross-dimer pairs, directed 3′ complementarity/extendability and terminal-composition evidence. These terms rank risk continuously. They are not a universal rejection threshold: LAMP nonspecific amplification is multi-factorial, and thermodynamic dimer strength alone is not treated as an assay-success oracle ([Kashir and Yamada 2018](https://pmc.ncbi.nlm.nih.gov/articles/PMC5922443/)). A computation cap or missing thermodynamic evidence is reported as unresolved rather than clean.

### Target inclusivity

A supplied homologous target panel activates an optional MAFFT alignment path ([MAFFT](https://mafft.cbrc.jp/alignment/software/)). Primer-region substitutions/deletions/insertions/ambiguity are mapped to reference coordinates and summarized by role, with mechanically critical inner-primer terminal events prioritized ahead of less critical events. Without a target panel, the result must not claim strain-, variant- or population-level inclusivity. This is conceptually distinct from background specificity.

### LAMP-native background specificity

For finite supplied backgrounds up to the declared direct-search limit, `background` is an **exclusion-only** scope: every compatible site/product is evidence to report, and no target-locus hit is silently subtracted. PCRStudio searches every required core target-derived region on **both genomic orientations** with an ungapped `<=2`-mismatch discovery model, then asks whether `F3/F2/F1c/B1c/B2/B3` can coexist on one locus with the selected LAMP order/spacing. Critical terminal nucleotides are recorded separately. The default `<=2`-mismatch and terminal-aware set-level concept is grounded in GLAPD's target/background strategy; PCRStudio's implementation remains independently bounded and explicitly reports its model/caps ([GLAPD](https://doi.org/10.3389/fmicb.2019.02860)).

A **pasted raw exclusion background** and a configured indexed BLAST database are not interchangeable evidence scopes. If pasted LAMP background exceeds the declared direct limit, the request now fails closed before candidate-specific scanning: PCRStudio will not silently assume that `PCRSTUDIO_BLAST_DATABASE` represents those pasted bases. For genome-scale specificity, omit the oversized raw panel and use an explicitly configured/approved indexed database. The indexed BLAST validator queries the six target-derived regions of the selected set(s) separately (splitting FIP/BIP and excluding any synthetic linker), retains full-length short-region hits, and reassembles them by subject, strand, orientation and selected geometry into LAMP-compatible loci. Both reference and reverse-complement whole-locus orientations are supported. Because BLAST's returned-hit limit and heuristic short-search behaviour do not constitute mismatch-complete enumeration, these counts are lower-bound compatible-locus evidence rather than a proof of absence. Intended target identity is also not inferred automatically, so a compatible database locus is not labelled an off-target until database/target semantics make that conclusion valid ([BLAST command-line applications](https://blast.ncbi.nlm.nih.gov/doc/blast-help/)).

### Search completeness and ranking claim

Candidate generation is hierarchical and bounded: role candidates → forward/backward halves → middle-gap/F2–B2 feasible core joins → bounded outer-primer expansion → diverse second-stage risk shortlist. Positional indexes/bisection remove impossible joins before expensive work, and spatial sampling is used when a declared budget is exceeded. Every truncation state is provenance. A truncated run may still return useful candidates, but it cannot claim exhaustive search or a global optimum. The ranking means “best under this declared profile, evidence set and computational budget”, never “universally best LAMP assay” ([Primer3 manual](https://primer3.org/manual.html)).

## Verification record

**Implementation:** validate every role, orientation, geometry relation, strand-displacing capability, selected readout and provenance ([Notomi et al.](https://doi.org/10.1093/nar/28.12.e63)).

**Test:** cover missing-role refusal, loop-primer on/off, reverse-complement input, incompatible enzyme, malformed geometry and readout mismatch ([Nagamine et al.](https://doi.org/10.1006/meth.2002.1264)).

**Limitation:** this profile is `limited`; specificity, time-to-positive and readout performance require the selected chemistry and control panel ([Soroka, Wasowicz and Rymaszewska](https://doi.org/10.3390/cells10081931)).
