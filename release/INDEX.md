# PCRStudio current public source

`CURRENT` is the public-source authority for Generation 1 on Linux x86_64. The active engine architecture is a single registry of 11 engines; no release-count engine families participate in generation, qualification or runtime behavior.

## Current authority

- [`STATUS.md`](STATUS.md) — current disposition.
- [`RELEASE-NOTES.md`](RELEASE-NOTES.md) — current changes.
- [`TOOLCHAIN-STATUS.md`](TOOLCHAIN-STATUS.md) — scientific/runtime toolchain boundary.
- [`current/CURRENT-ENGINE-SYSTEM.md`](current/CURRENT-ENGINE-SYSTEM.md) — unified engine architecture.
- [`current/CURRENT-LINUX-MIGRATION.md`](current/CURRENT-LINUX-MIGRATION.md) — Linux migration record.
- [`current/CURRENT-LINUX-QUALIFICATION.md`](current/CURRENT-LINUX-QUALIFICATION.md) — native qualification sequence.
- [`current/CURRENT-STATIC-CONSISTENCY-AUDIT.md`](current/CURRENT-STATIC-CONSISTENCY-AUDIT.md) — reproducible source consistency evidence.

`release/baseline/` preserves the immutable historical baseline required for provenance. Historical identifiers there are evidence only and are not active architecture.
